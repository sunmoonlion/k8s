# Celery Worker Incubator 重构方案

## 目标

将多后端模式的 `celeryworker-bff` 改造成单后端独立 Worker，专门为 `incubator-app-bff` 服务。

## 当前状态

- ✅ 目录已重命名为：`celeryworker-incubator`
- ❌ 配置文件仍为多后端模式（包含 llmops 和 incubator）
- ❌ 部署脚本仍为多后端逻辑（代码合并）
- ❌ YAML 模板仍为多后端模板（多个 Init Container + 代码合并）

## 重构步骤

### 步骤1：简化配置文件

**文件路径**：`deploy-celeryworker-bff/deploy-multi-celeryworker.conf`

**重命名为**：`deploy-celeryworker-incubator/deploy-celeryworker-incubator.conf`

**需要修改的内容**：

1. **移除多后端配置**：
   - 删除 `BACKEND_llmops_*` 相关配置
   - 删除 `BACKEND_scrapy_*` 相关配置（如果有）
   - 只保留 `incubator` 相关配置，但改为单后端格式

2. **改为单后端配置格式**：
   ```bash
   # 原多后端格式（删除）
   BACKEND_incubator_IMAGE="incubator-app-bff"
   BACKEND_incubator_TAG="1.0.0"
   BACKEND_incubator_CODE_EXTRACT_DIRS="worker core services db models"
   
   # 改为单后端格式（使用）
   BACKEND_IMAGE="incubator-app-bff"
   BACKEND_TAG="1.0.0"
   BACKEND_IMAGE_REGISTRY="harbor.sunmoonai.com:30443"
   BACKEND_IMAGE_PROJECT="k8s-images"
   CODE_EXTRACT_SOURCE_DIR="/app/app"
   CODE_EXTRACT_DIRS="worker core services db models"
   CODE_EXTRACT_FILES="__init__.py"
   ```

3. **修改队列配置**：
   ```bash
   # 原多后端格式（删除）
   CELERY_QUEUES="llmops-queue,incubator-queue"
   
   # 改为单队列格式（使用）
   CELERY_QUEUE="incubator-queue"  # 注意：单数 QUEUE，不是 QUEUES
   ```

4. **更新资源名称**：
   ```bash
   # 原多后端名称（修改）
   CELERY_WORKER_IMAGE="celeryworker"  # 可以改为 "celeryworker-incubator" 或保持原样
   ```

5. **删除不需要的配置**：
   - 删除 `DEFAULT_BACKEND_*` 相关配置（单后端不需要）
   - 删除多后端相关的注释说明

### 步骤2：简化部署脚本

**文件路径**：`deploy-celeryworker-bff/deploy-multi-celeryworker.sh`

**重命名为**：`deploy-celeryworker-incubator/deploy-celeryworker-incubator.sh`

**需要修改的内容**：

1. **更新脚本注释和名称**：
   ```bash
   # 原：Celery Worker 多后端部署脚本
   # 改为：Celery Worker (Incubator) 部署脚本
   ```

2. **更新配置文件路径**：
   ```bash
   # 原：
   CELERY_WORKER_CONFIG_FILE="$SCRIPT_DIR/deploy-multi-celeryworker.conf"
   
   # 改为：
   CELERY_WORKER_CONFIG_FILE="$SCRIPT_DIR/deploy-celeryworker-incubator.conf"
   ```

3. **更新资源文件路径**：
   ```bash
   # 原：
   CELERYWORKER_YAML="${RESOURCES_DIR}/multi-celeryworker.yaml"
   GENERATED_YAML="${RESOURCES_DIR}/multi-celeryworker-generated.yaml"
   
   # 改为：
   CELERYWORKER_YAML="${RESOURCES_DIR}/celeryworker-incubator.yaml"
   GENERATED_YAML="${RESOURCES_DIR}/celeryworker-incubator-generated.yaml"
   ```

4. **删除多后端相关函数**：
   - 删除 `get_enabled_backends()` 函数
   - 删除 `generate_init_container_yaml()` 函数
   - 删除 `generate_all_init_containers()` 函数
   - 删除 `generate_backend_list()` 函数

5. **简化部署函数**：
   - 在 `deploy_celeryworker()` 函数中：
     - 删除动态生成 Init Container 的逻辑
     - 删除后端列表生成的逻辑
     - 删除代码合并相关的环境变量导出
     - 简化为单后端配置导出

6. **更新 YAML 生成逻辑**：
   - 删除 `generate_template_yaml()` 函数中的代码合并逻辑
   - 简化为单 Init Container 提取代码
   - 删除 `merge-code` Init Container（不需要合并）

### 步骤3：简化 YAML 模板

**文件路径**：`resources/multi-celeryworker.yaml`（如果存在，或由脚本生成）

**重命名为**：`resources/celeryworker-incubator.yaml`

**需要修改的内容**：

1. **更新 Deployment 名称和标签**：
   ```yaml
   # 原：
   metadata:
     name: celeryworker-multi
     labels:
       app: celeryworker-multi
   
   # 改为：
   metadata:
     name: celeryworker-incubator
     labels:
       app: celeryworker-incubator
   ```

2. **简化 Init Containers**：
   ```yaml
   # 原：多个 Init Container + merge-code
   initContainers:
     - name: extract-llmops-code
       ...
     - name: extract-incubator-code
       ...
     - name: merge-code
       ...
   
   # 改为：只有一个 Init Container
   initContainers:
     - name: extract-incubator-code
       image: ${BACKEND_IMAGE_REGISTRY}/${BACKEND_IMAGE_PROJECT}/${BACKEND_IMAGE}:${BACKEND_TAG}
       volumeMounts:
       - name: worker-code
         mountPath: /shared
       command:
         - sh
         - -c
         - |
           echo "从 incubator-app-bff 镜像提取任务定义代码"
           SOURCE_DIR="${CODE_EXTRACT_SOURCE_DIR}"
           TARGET_DIR="/shared/app"
           mkdir -p "$TARGET_DIR"
           # 复制目录和文件（简化逻辑，直接复制，无需合并）
           for dir in ${CODE_EXTRACT_DIRS}; do
             if [ -d "$SOURCE_DIR/$dir" ]; then
               cp -r "$SOURCE_DIR/$dir" "$TARGET_DIR/"
             fi
           done
           for file in ${CODE_EXTRACT_FILES}; do
             if [ -f "$SOURCE_DIR/$file" ]; then
               cp "$SOURCE_DIR/$file" "$TARGET_DIR/"
             fi
           done
   ```

3. **更新 Service 名称**：
   ```yaml
   # 原：
   metadata:
     name: celeryworker-multi-service
     labels:
       app: celeryworker-multi
   
   # 改为：
   metadata:
     name: celeryworker-incubator-service
     labels:
       app: celeryworker-incubator
   ```

4. **更新环境变量**：
   ```yaml
   # 原：多队列
   env:
     - name: CELERY_QUEUES
       value: "llmops-queue,incubator-queue"
   
   # 改为：单队列
   env:
     - name: CELERY_QUEUE
       value: "incubator-queue"
   ```

## 关键修改点总结

### 1. 配置文件简化
- ✅ 移除多后端配置，只保留 incubator
- ✅ 改为单后端格式（`BACKEND_IMAGE` 而不是 `BACKEND_incubator_IMAGE`）
- ✅ 单队列配置（`CELERY_QUEUE` 而不是 `CELERY_QUEUES`）

### 2. 部署脚本简化
- ✅ 删除多后端相关函数
- ✅ 删除代码合并逻辑
- ✅ 简化为单 Init Container 提取

### 3. YAML 模板简化
- ✅ 只有一个 Init Container（提取代码）
- ✅ 删除 merge-code Init Container
- ✅ 更新资源名称和标签

### 4. 环境变量简化
- ✅ `CELERY_QUEUES` → `CELERY_QUEUE`
- ✅ 删除多后端相关的环境变量导出

1. **数据库 Secret**：确认 incubator-app-bff 使用的数据库 Secret 名称
2. **队列名称**：确认后端服务发送任务时使用的队列名称
3. **镜像标签**：确认 incubator-app-bff 的镜像标签版本
4. **代码提取路径**：确认 incubator-app-bff 镜像中的代码路径
