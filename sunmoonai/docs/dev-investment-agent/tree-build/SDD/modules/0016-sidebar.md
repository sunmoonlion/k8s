# 侧边栏：按真源分层（0016）

> 状态：所有者 2026-10-11 确认分层「电脑 → 工作区 → 项目 → 对话」，远程写设计，未实施。以现网 luna 分支的网页为基线（fable 的网页落后于它）。取代 `PRD/apps/investment.md` 侧栏三行（侧栏顶部 / 中部 / 底部）与 `SDD/modules/0002-web-pages.md`「框架」一行里关于中部与底部的描述。与 0015（改动面板）、`approval.md`「待我决定只留定位」配套。

## 一、分层（所有者确认）

| 层 | 真源在哪 | 网页能做什么 |
| --- | --- | --- |
| 电脑 | 本地代理配对后在工作台登记（`workbench_environments`） | 看清单与在线灯；接入与上限在设置页「我的电脑」 |
| 工作区 | 电脑上代理的白名单根目录 | 只显示；加减在电脑上的代理里做 |
| 项目 | 工作区下的一个子目录，`cwd` | 建、改名、归档、打开 |
| 对话 | 挂在项目下：聊天、工作、专家 | 新建、打开 |
| 待我决定 | 名下 pending 的 Interaction | 数字 + 定位，不放按钮 |

侧边栏是**导航**，只摆真实存在的东西和它们的从属关系；管理动作放在各自的页面。文件树不进侧边栏，进对话页右侧的改动面板（0015）。

### 3.1 中段规则

| 项 | 规则 |
| --- | --- |
| 电脑行 | 每台一组：名字、在线灯（在线 / 离线 / 从未）、「管理」小链接到设置页「我的电脑」锚点。只有一台时也显示这一行，因为它告诉用户文件在哪 |
| 没有电脑 | 中段只一行：「还没有接入电脑。接入后，你的目录和项目会出现在这里。」加一个到设置页的链接。不弹卡、不逼人去（账 76） |
| 工作区行 | 在电脑组下，每个白名单根目录一行，显示路径尾段，悬停显示全路径。默认折叠，只展开**当前项目所在**的那个；用户手动展开收起记在本地 |
| 没有工作区的电脑 | 组下一行：「还没有加目录。在这台电脑的代理里加一个，项目才有地方放。」 |
| 项目行 | 名字；右侧两个标记：● 专家正在这个项目的某段对话里做事；数字 = 这个项目里等用户决定的件数。点行进项目页 |
| 工作区里没有项目 | 一行「新建项目」 |
| 「全部项目」 | 中段标题右侧保留，进项目列表页 |
| 最近 | 保留，跨项目最近 N 段对话；每行：模式图标、名字、所在项目名（小字）；● 专家在做；▲ 等你。对话不嵌进项目树（太深），项目页里才列全 |

| 用量 | 不在侧边栏，仍在对话顶部的花费钮 |
