# 数据流与信任边界

> 由产品合同搬入。哪条数据走哪条通道，见 [通道](channels.md)。

**口径是「不经过我们」，不是「不出本机」。**只要模型在云上，Codex 读过的内容就离开了
这台机器——写成「不出本机」是假的。我们承诺的是：**资料与结果正文不经我们的后端、
不经知识服务**；发往哪家模型厂商由用户自选、自付，提交前界面告知。


| 数据 | 流向 |
| --- | --- |
| 用户 key | 只在用户电脑，只发给用户选择的模型厂商 |
| 用户提出的问题（任务文本、归一化目标、已确认的类别） | 明文发到后端，用于受理判定、路由与编排 |
| 用户自己的资料、文件名、Codex 取回的公开资料 | 存在用户电脑上的本地知识库，**不上传后端**；提交时只给句柄。⚠ 这一行说的是**存放与提交**；Codex 在执行中读过的内容按下一行处理 |
| 文件与研究内容 | **由 Codex 发给用户选择的模型厂商**；不上传后端。⚠ 这就是「不经过我们」的确切含义——内容确实离开这台机器，只是不经我们的后端；界面必须在提交前告知是哪一家 |
| 自有数据 | 按查询以片段形式下发到用户电脑 |
| 查询内容 | 发到知识服务；日志少记并告知用户 |
| 工具级审批细节（命令原文、改动、路径） | 只在本地窗口展示；后端只收摘要与结论 |
| 研究结果 | 本地检查后加密，后端只存密文与元数据，无法读取 |
| 任务元数据（状态、时间、用量、审计摘要、密文摘要值） | 后端 |
