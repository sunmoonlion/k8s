# 产品验收矩阵

> `AT-*` 是产品级验收；对应的功能义务 `F-*` 在各模块文档里，谁负责见 [责任投影](../SDD/architecture/ownership.md)。
> ⚠ 本文件存在不证明能力已落地。宣布某项能力已实现前，至少提供下列自动化或可复现实验。

| ID | 场景 | 必须证明 |
| --- | --- | --- |
| `AT-01` | 幂等重复提交 | 同作用域、同键、同摘要只创建一个 Task |
| `AT-02` | 幂等异载荷 | 同键异摘要明确冲突，不误复用、不另建 |
| `AT-03` | 协议拒绝 | 未认证或畸形提交不创建 Task，不泄露信息 |
| `AT-04` | 受理拒绝 | 已建单 Task 可进入 `REJECTED` 并返回安全理由 |
| `AT-05` | 越权访问 | 不能读取、订阅、恢复、批准或取消其他用户的 Task、thread、工作区 |
| `AT-06` | 方向盘交接 | 用户交出方向盘后自己发 turn 被拒；顾问交回后顾问发 turn 被拒；交接双方都有事件 |
| `AT-07` | 澄清恢复 | 令牌原子消费；重复、过期、异键、跨 Task、摘要不符的响应被拒绝 |
| `AT-08` | 执行环境断线 | 顾问驾驶中执行环境断开：Task 进 `WAITING(ENVIRONMENT)`，不退回沙箱本地执行，恢复后续跑或开新 Attempt |
| `AT-09` | 本地上限 | 沙箱请求超出本地代理上限的沙箱模式、根目录或网络时，执行环境拒绝，且拒绝可观测 |
| `AT-10` | Attempt 重试 | 可重试失败产生新 Attempt，Task 不被过早终结 |
| `AT-11` | 验收失败 | 不合格输出不能使 Task 成功；可按策略产生新 Attempt；验收依据是派工时冻结的 |
| `AT-12` | 预算硬停 | 超限的 Attempt 进终态；Task 进 `WAITING(RESOURCE)`；追加须用户明确批准；顾问不能自行加步 |
| `AT-13` | 取消竞争 | 取消意图先持久化；完成与取消只有一个终态胜出 |
| `AT-14` | 服务重启 | 可重建所有非终态 Task、Attempt、等待中的 Interaction、方向盘状态 |
| `AT-15` | 网页断线 | 按 cursor 回放无缺口，重复事件被去重 |
| `AT-16` | 通知失败 | Task 终态不变，Delivery 独立重试 |
| `AT-17` | Profile 升级 | 历史 Task 仍按固定版本解释和复现 |
| `AT-18` | 工具级审批 | 命令与文件修改经协议回到工作台；本地上限之内的按策略处置，之外的本机当面确认；断线时未决审批作废 |
| `AT-19` | 越出工作区 | 顾问驾驶的写入只落在用户选定的项目目录；越出即审批 |
| `AT-20` | 定位拦截 | 对具体证券的评级、目标价、走势预测、买卖建议被云端检查拦截并留痕 |
| `AT-21` | key 不外泄 | 用户 key 只在密钥库与沙箱进程环境；不进事件、日志、界面、执行环境 |
| `AT-22` | 边缘无状态 | 换掉任一台边缘机器，会合点连接重建后会话与 Task 不丢 |
| `AT-23` | 内网只出站 | 内网站点与用户机器没有任何入站监听被边缘依赖；扫描证明 |
| `AT-24` | 步骤交回 | 交回物不满足 `output_schema` 时按 `on_reject` 处置且不使 Task 失败；下一步只取固定版本的 Artifact |
| `AT-25` | 交回物契约 | 顾问交回时四项齐全：做了什么、什么已核实、什么未知、工作区怎么恢复 |
| `AT-26` | 质量信号 | 引用为零、时点过期、勾稽不平等信号按规则触发提示；不调模型；可关闭 |
| `AT-27` | 对比评测 | 冻结任务集上四臂按 Profile 报告；改动后回归；费用一列参与判负 |
| `AT-28` | 版本成对 | app-server 与 exec-server 版本不匹配时拒绝连接并提示，不静默降级 |

此外必须满足：

1. Task 与 Attempt 状态迁移、API schema、会合点协议、事件 schema、Profile schema 与错误码有机器可检查的版本；
2. 每个 `F-*` 与 `I*` 登记实现所有者、代码位置、自动测试与当前覆盖状态；
3. 无法自动化的条款登记人工门禁、理由与复核证据；
4. 至少一个真实 Task 在 Linux 或 macOS 上跑通：网页提交、求助、顾问驾驶、本机审批、验收、底稿落工作区、断线回放；
5. 项目事实与目标规范分开，未实现能力不写成已有。
