# 用户说明：账号、云端沙箱、本地代理

> 写给用户看的，不写技术细节。网页设置页、「我的机器」页上的提示文字从这里摘（`SDD/modules/0002-web-design.md` 4.6、4.7）。
> 末尾「开发阶段与正式版的差别」一节只给内部测试的人看，不对外。

## 先弄清三样东西

用 SunMoon AI 做研究，要有三样东西，各管一件事：

| | 是什么 | 在哪 | 你要做什么 |
| --- | --- | --- | --- |
| **账号** | 你是谁 | 网站上 | 注册一次（要邀请码和邮箱验证码），之后用用户名或邮箱登录 |
| **云端沙箱** | 替你思考、动手的 AI 助手（Codex）住的地方 | 我们的服务器上，只属于你 | 在设置页填一次模型 key，点一次「拉起沙箱」 |
| **本地代理** | 让云端助手能在你电脑的指定文件夹里读写文件、运行命令的小程序 | 你自己的电脑上 | 装一次、接入一次，之后开着就行 |

打个比方：沙箱是在云端上班的研究助理，本地代理是你给他的一把只能开某几个抽屉的钥匙。他想看你的资料、在你的文件夹里写东西，都要通过这把钥匙；抽屉以外的地方他进不去。

## 第一次使用：按顺序做一遍

1. **注册、登录。** 在首页点「有邀请码？注册」，填邮箱并收验证码，设用户名和密码，填邀请码。以后登录用户名或邮箱都行。
2. **填模型 key。** 进「设置」，在「模型 key」里选厂商（比如 Kimi），粘贴你的 API key，提交。key 只保存加密后的样子，页面上只显示最后四位；我们的人看不到原文。
3. **拉起沙箱。** 在「设置 → 我的沙箱」点「拉起沙箱」。状态会从「启动中」变成「运行中」，一般一两分钟。
4. **接入本地代理。** 拉起沙箱时，页面会给你一条**接入命令**。这条命令**只显示这一次**，里面有一把只属于你的钥匙：
   - 复制它，在你的电脑上运行（正式版是在代理程序里点「接入」粘贴进去）；
   - 不要发给别人，不要贴到聊天里；
   - 丢了也不要紧，去设置页点「换代理令牌」重新拿一条（旧的立即作废）。
5. **选允许助手动的文件夹。** 在代理里把你的研究资料所在的文件夹加进「允许的目录」。只有这些文件夹里的东西助手能看、能改。
6. **开始研究。** 回到网页新建会话：选你的电脑、选你的沙箱、选项目文件夹，就可以和助手对话了；需要时点「问专家」把活交给专家。

做完这六步，以后每次只需要：**打开网页、登录、开始研究**。

## 设置一次之后，什么时候还要再动

| 情况 | 要做什么 | 不用做什么 |
| --- | --- | --- |
| 电脑重启、关机后再开 | 确认本地代理在运行（正式版会开机自动运行，托盘里能看到它） | 不用重新接入 |
| 换了一个模型 key | 设置页提交新 key，再点「更新沙箱」（助手重启一下，约一分钟） | 不用重新接入代理 |
| 接入命令丢了，或怀疑被人看到了 | 设置页点「换代理令牌」，用新命令重新接入 | 沙箱不受影响，之前的研究记录还在 |
| 暂时不用了，想释放云端资源 | 设置页点「回收沙箱」 | 研究记录保留；再点「拉起沙箱」就恢复原样，不会给新的接入命令 |
| 我们升级了助手版本 | 按提示更新本地代理（正式版会自动更新） | — |
| 网页提示「云端沙箱暂时满了」 | 稍后再试；你的 key 和设置都保留着 | — |

## 常见的「为什么」

- **新建会话时「机器」「沙箱」下拉是空的？** 多半是还没做第 3、4 步；或者登录的不是当初设置用的那个账号——每个账号只看得到自己的机器和沙箱。本地代理没开时，你的电脑仍会出现在列表里，只是标成「离线」。
- **助手说"执行环境断开"？** 本地代理没在运行，或者电脑睡眠了。把代理打开，等状态变成「已连接」再继续。
- **同一个账号能在两台电脑上用吗？** 可以装两个代理，但同一时刻只能有一个在线；第二个上线时，第一个会自动停下并提示你（避免两边抢）。
- **助手能看到我电脑上所有东西吗？** 不能。只有你加进「允许的目录」的文件夹；想放宽权限时，代理会在你电脑上弹窗让你当面确认。
- **我的 key 会被别人用吗？** key 加密保存，只在你的沙箱里使用；模型的费用走你自己的 key。你可以随时在设置页撤销它。

## 开发阶段与正式版的差别（内部测试看）

现在的测试环境里，下面几件事和正式版不一样：

- 放宽权限时的"电脑上弹窗确认"还没做：现在超出上限的请求一律被代理拒绝。
- 本地代理还没有安装包和托盘，是命令行程序：接入是 `init`（只做一次），运行是 `start`（每次开机后要手动再运行一次，不用再 `init`）；同一台电脑上一个账号只开一个 `start`。
- 接入命令先存到自己电脑的私有文件（如 `~/private/agent-init.txt`，权限 0600），再由本地助手按文件执行，不贴进任何对话。
- 在本地 KIND 里，接入地址要换成集群节点的端口地址（`ws://<节点 IP>:30471`），正式版是网页给出的 `wss://` 地址，不用改。
- 设置页的 key 列表、委托卡片的实时刷新、未登录时的提示，有几处已修未发版，个别地方要刷新页面才看得到。
