## 一处欠账：承诺过的映射表从未产出

`refact-fable.md` §5.2 标题是「旧 → 新映射：按旧文全部标题，脚本检查零缺口」，
正文写：

> 枚举两份旧文档全部 `##` / `###` 标题，每个标题必须有且只有一个落点……
> 映射表本身是 R5 的产物 `rounds/<id>/migration-map.md`，由一个脚本生成骨架、
> 检查零缺口，并进 L0 机器门。

**实测：`migration-map.md` 从未存在**（`git log --all` 零命中）；该节计划的三个目标文件
`lifecycle.md` / `authority.md` / `executor-architecture.md` **一个都没建过**。
架构随后改了方向，这张表就搁下了，而 2427 行压成 940 行这件事**至今没有逐节交代**。

这不是谁失职，是**判据写在计划里、没写进验收条件**的后果：
承诺产出但不进验收，等于没承诺。本目录乙格的存在就是这笔欠账的账面。

## 本目录不能删 —— 这是一条可判的条件，不是态度

所有者 2026-09-07：**「这样的话，`archive` 就不能删了」**。成立，条件如下：

> **只要 `../agent-dev-guide.md` §10 还有任何一行的落点没验到正文级，
> 本目录下对应的源稿就不能删。**

理由不是「留着以防万一」，是**可证伪性**：§10 开头自己写着
「这张表是覆盖的索引，不是覆盖的证明……核它的办法是**抽查落点、以正文为准**」。
被抽查的对象就在本目录。**把它删掉，这张表就从「可证伪」变成「不可证伪」**——
而一份不可证伪的覆盖声明**比没有更差**，因为它看起来像交代过了。

⚠ **「git 历史里有」不算数。**该文 §3.5 已立：**Git 历史可恢复不等于新读者能找到。**

**现在离满足这个条件还差多少：**

## 引用它们的锚点

删除或移动被引文档会让 `` `文件.md:行` `` 这类纯文本锚点失效，而
[`../doc-gate.py`](../../tools/doc-gate.py) 只查 markdown 链接，**查不出这一类**——
[`../anchor-gate.py`](../../tools/anchor-gate.py) 就是为此建的。活文档里的 5 处裸路径锚
已改钉版锚 `@ ceb7291c:<行>`；`rounds/**` 内的 111 处按归档软判，不改。
`archive/**` 自 2026-09-07 起同样按软判：归档是冻结的历史记录，锚点按成文时状态解析。
**软判是豁免判失败，不是豁免报出来**——`anchor-gate` 仍逐条列出。
