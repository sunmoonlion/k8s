# 账号、电脑、link、会合点：四样东西、四种关系

> Opus 2026-10-20 备忘。起因：qwen-012 第 4 行核「这台电脑改连到 sig-am 了没有」时，Opus 几次把这四样混着说，所有者「我一直开发的人都听的莫名其妙」「你根据的是link不是电脑判断」，理清后「现在才真正搞清楚了，但你现在的代码没这样实现啊」。
> 本页写**概念与现在代码的实际做法**；要改的做法记在待办账 143（[`pending-after-migration.md`](dev-investment-agent/tree-build/pending-after-migration.md)），还没做。
> **以后界面、文档、卡片只用本页的四个关系词：装在、登录、配给、连着。**

## 一、四样东西

| 东西 | 是什么 | 在哪 | 我们能知道它什么 |
| --- | --- | --- | --- |
| **账号** | 一个身份（如 sig-am） | 云端（Casdoor 登录） | 全部 |
| **电脑** | 一台实体机器 | 用户手里 | **什么都不知道**，只能听 link 说 |
| **link** | 装在电脑上的本地程序 sunmoon-link | 用户的电脑上 | 它自己报的：电脑名（默认是操作系统主机名，可用 `--name` 或本机设置改）、连没连着会合点 |
| **会合点** | link 往外连的中转服务器（relay）；工作台经它和 link 说话 | 云端 | 每个账号此刻有没有 link 连着 |

## 二、四种关系

| 关系 | 谁和谁 | 怎么建立 | 一对几 |
| --- | --- | --- | --- |
| **装在** | link 装在电脑上 | 安装 | 一台电脑装一份 link |
| **登录** | 浏览器用账号登录 | 在浏览器里登录 | 和另外三种关系**毫无关系**：浏览器登的是 A，这台电脑的 link 可以配给 B |
| **配给** | link 配给某个账号 | 托盘「重新连接账号」→ 浏览器确认页「允许后，这台电脑连到账号「X」」→ 点「允许」，link 拿到**这个账号的令牌** | 一份 link 同时只配给一个账号；一个账号同时只配给一份 link——令牌按账号发，再配一次旧令牌作废、旧的 link 断开 |
| **连着** | link 连着会合点 | link 拿令牌往外连，自动保持、断了自动重连 | 实时：电脑关、没登录 Windows、link 没跑、断网、令牌过期（30 天，待办账 132）就不连着 |

- 「**配给这个账号的 link**」= 最后一次给这个账号点「允许」的那份 link。配给关系配好就一直在，直到下次重新配对。
- 账号不去连谁；说「账号连着的 link」是错的，要分成「配给这个账号的 link」和「它连没连着会合点」两句。

## 三、几个词的实际意思

| 界面上的词 | 实际意思 | 怎么判断（现在的代码） |
| --- | --- | --- |
| 在线 | 配给这个账号的那份 link，此刻连着会合点 | knowbench 后端每 10 秒问一次会合点哪个账号有 link 连着（`application/workbench/machines.py` `MachineSync`）：有，就按它报的**电脑名**找记录（没有就建）、标在线，这个账号别的记录标离线；没有，全标离线；会合点问不到，什么都不改 |
| 离线 | 配给这个账号的 link 此刻没连着会合点——**说的是 link，不是电脑**：电脑开着、link 没跑也是「离线」 | 同上 |
| 最近一次联系 | 最后一次对账看到它连着的时间 | 同上 |
| 就是这台（侧栏「我的电脑与项目」） | 猜「浏览器所在这台电脑上的 link」就是账号下在线的那条 | 网页探本机 `http://127.0.0.1:47811`（占了依次试 47812–47815）的 `/presence`，link 回电脑名与「连没连着」；拿电脑名和账号下的记录**按名字比**（knowbench 网页 `lib/workbench/local-agent.ts`、`features/shell/model/nav.ts` `presenceHint`）。`/presence` 有来源检查，只有我们的工作台能读 |
| 你现在用的这台电脑连在别的账号上 | 推断：本机 link 连着会合点，账号下同名记录却离线 → 本机 link 多半配给了别的账号 | 同上（link 不说自己配给了谁，只能这样绕） |

另外两件相关的事：

- **会合点会断掉卡死的 link**：会合点每 20 秒 ping 一次 link，不回就断开，所以后端看到的「离线」比 link 自己说的可靠。但 link 那头卡在半开连接时不会自己重连（待办账 136），要在托盘重启；代理 0.5.1 修。
- **登录自启**：配对完成时 link 自动打开「登录 Windows 时自启」（任务计划程序里当前用户的登录任务，后台隐藏运行，失败每分钟重启、最多 3 次）；托盘可开关。开机后停在登录界面，link 不跑。

## 四、常见情形

| 情形 | 配给 | 连着 | 界面 |
| --- | --- | --- | --- |
| 在电脑 P 上给账号 A 点「允许」 | P 上的 link → A；A 之前配给的 link 作废 | P 开着就连着 | A 下 P 在线 |
| 电脑 P 关机，或没登录 Windows | 不变 | 不连着 | A 下 P 离线 |
| 在电脑 Q 上又给 A 点「允许」 | Q 上的 link → A；P 上的作废 | Q 连着 | A 下 Q 在线、P 离线 |
| 在电脑 P 上给账号 B 点「允许」 | P 上的 link → B；它不再配给 A | 连着（替 B） | B 下 P 在线；A 下 P 离线，A 在 P 上开网页时侧栏写「你现在用的这台电脑连在别的账号上」 |
| 用手机开工作台 | 不变 | 不变 | 侧栏「这台电脑还没接入」（手机上没有 link） |
| 两台主机名一样的电脑先后配给 A | 后配的那台 | — | **现在会并成一条记录、可能标错「就是这台」**（按名字认，账 143） |

## 五、现在的代码哪里不对（详见待办账 143）

1. 按**电脑名**认 link：后端登记、侧栏比对都是，同名就合并或认错。
2. link 的状态说成了电脑的状态（「电脑在线、离线」）。
3. link 不说自己配给了哪个账号，只能绕着推断。
4. 结果只挂在侧栏小字里，不提示该做什么。
5. 浏览器不让探本机时，和「没装 link」看上去一样。

要改成（所有者定：**提示不放栏目里**，「直接根据上面的四个分类单独提示就可以了，这个放在栏目里吗用户不懂反而糊涂啊」——侧栏去掉「就是这台」「连在别的账号上」这类标签，只留项目与电脑名；核对结果在工作台顶上单独提示，一切正常不提示）：link 由配对时的设备密钥导出**设备编号**来认；打开工作台时核对「浏览器所在这台电脑上的 link，是不是配给当前登录账号的那份」，是而且连着就不打扰，不是就提示重新连接。四种结果见账 143；要发代理新版，暂停结束后与代理 0.5.1 一起出。
