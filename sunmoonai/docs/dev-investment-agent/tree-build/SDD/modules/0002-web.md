# `0002-web` 网页

> 产品界面。映射 `investment-app/investment-web-frontend`（Next.js 16）；从"只剩官网"改回产品界面。静态产物或无状态进程放边缘，`/api/` 经隧道到内网。
> 旅程、信息架构、页面规格与组件见 [网页设计](0002-web-design.md)（初稿待所有者改）。

## 页面

| 页 | 做什么 |
| --- | --- |
| 登录与注册 | Casdoor OIDC + PKCE，会话在工作台；登录页有「注册」入口，走 Casdoor 注册页（邀请码 + 邮箱验证码，见 `security.md`「账号与注册」）；登录可填用户名或邮箱 |
| 环境与工作区 | 看已注册的本地代理、在线状态、白名单；选工作区与项目；建 Session |
| 对话（第一层） | 与自己的 Codex 对话：发 turn、看事件、答工具级审批；质量信号提示条 |
| 求助（第二层入口） | 写问题、选专家包、设预算、显式上传资料；交出方向盘 |
| 进度 | Task 状态、当前步骤、Attempt、费用；取消 |
| 审查 | Interaction 列表与详情；批准、拒绝、回答 |
| 底稿 | 结果、证据、交回物、工作区变更；结论栏编辑 |
| 设置 | key 录入与撤换；模型；`approvalPolicy` |

## 功能义务

| ID | 义务 |
| --- | --- |
| `F-WEB-01` | 不持任何凭据；key 录入只经 HTTPS 提交，本地不留（`C-D9`） |
| `F-WEB-02` | 事件流按 cursor 续传；断线后回放无缺口、去重（`AT-15`） |
| `F-WEB-03` | `wheel=advisor` 时对话输入禁用并说明原因；可取消、可答 Interaction |
| `F-WEB-04` | 审查面表达 [审批](../architecture/approval.md) 要求的五要素；同一 Interaction 只开一个 |
| `F-WEB-05` | 底稿页结论栏空白或标为用户草稿；不渲染任何评级、目标价字段 |
| `F-WEB-06` | 从工作台的 OpenAPI 生成客户端；不手写第二份 |
| `F-WEB-07` | 本地代理未装或离线时给出安装与状态指引；不阻塞浏览与设置 |

## 不做

Electron；本地能力（文件、进程）；与本地代理直连（一切经工作台）。

## 与平台模板的关系

按 `C-R6`，公共能力（登录、会话、事件流客户端）先进 `tpl-app` 模板，再同步到本仓。
