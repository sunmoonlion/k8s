## 3. 本单元最该记的一条

**两道门禁都看不见「有标题没正文」。**

裁决方自验时跑 `doc-gate --all` + `anchor-gate.py` 全绿，据此宣布判据 1 满足。
但空标题**不产生锚点**，`anchor-gate` 无从判起；`doc-gate` 只查链接与表格列数，也不看正文。
验收方抓到它，靠的是**逐节对照原文、确认「不经 git 历史能否读到正文」**——那正是判据 1 的字面要求。

这是本项目记录的「判据给假答案」的**第七次**，且形态是新的：

| 前六次 | 本次 |
| --- | --- |
| 判据在**边界条件**上给出错误结论（`all({})` 报完成、判别命令吐点、消歧句被当证据、边检查误报、`\|\| true` 吞错、`doc-gate` 看不见纯文本锚） | **判据的覆盖面根本不含这一类**——门禁绿只代表它查的那些项没问题，不代表判据满足 |

**推论**：`门禁全绿` ≠ `判据满足`。把前者当后者，是用「工具查了什么」替换「判据要求什么」。
这条与前六次合并为同一纪律的第七个实例，`⑦` 清理时一并提为 `round-protocol` 正式纪律。
