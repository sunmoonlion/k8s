# ADR-0004：对象存储按领域拥有和隔离

- 状态：已接受
- 日期：2026-06-11

## 背景

多个 App 需要保存文件和处理产物。共享目录或不区分所有者的 Bucket 会造成权限、生命周期和数据恢复责任不清。

## 决策

文件由其业务领域 App 拥有。平台通过 S3 API 提供对象存储，不把领域模型绑定到具体产品。物理对象存储可以共享，但必须使用独立 Bucket、凭据、生命周期和访问策略。

Kind 环境长期使用固定版本 MinIO；远程环境选择仍受维护并满足高可用、备份和恢复要求的 S3 兼容实现。

跨 App 通过对象引用、短期授权地址和内容哈希交换文件。需要长期处理的接收方创建有来源记录的受控副本。

## 结果

- `info-app` 的原始资讯 Bucket 是权威主档。
- RAGFlow MinIO 只保存知识处理副本。
- `tools-app` 不拥有调用方业务文件。
- 不以共享宿主机目录作为正式交换协议。
