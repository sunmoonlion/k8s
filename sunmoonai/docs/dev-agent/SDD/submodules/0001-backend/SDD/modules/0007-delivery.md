# 0007-delivery：交付

**承担**：把结果送到用户手里，并保证他以后还能取到。

- 事件流投影与 **cursor 续传**：客户端断线、重启、换设备后按 cursor 接着读，**重复事件幂等**；
- 结果**密文**的存取；
- 通知：有结果了、有待审查了。

**不承担**：

- **不解密**——只存密文与元数据，明文从不进后端；
- 不判验收，那是 [`0006-acceptance`](0006-acceptance.md)；
- 不写状态与账，经 [`0001-state`](0001-state.md)。

**朝客户端（通道 ④）**，和 `0002-router` 一入一出。

**边界要点**：**先持久化后通知**——通知只是提醒，丢了不影响结果。所以**通知失败可以独立重试，
不改变 Task 结果**；有权用户在断线、应用重启或换设备后，**凭结果密钥可以重新取得**结果。
这两条是生命周期终点判据的一半，也是这一块与验收分开的理由：验收是一次性的判断，
交付是**长期可取**的能力。
