## ⚠ 利益冲突：这五份全部由 opus 起草，而 opus 是本轮参赛方

旧任务书 `pipeline-task.md` §13.1 已经处理过这件事——当时的办法是让 opus 退出提案、
只任裁决整合。**本轮不同：所有者定五家全参赛含 opus，裁决方是所有者本人。**
所以那四条约束改写如下，**由所有者在 ③ 裁决时执行**：

1. **候选与本目录任何一份冲突时，默认采纳候选**，除非有可复跑的取证支持后者。
2. 凡采纳与本目录一致的主张，处置记录必须写明**它比其他候选好在哪**，
   不得只写「与参考材料一致」。
3. **不得因为某份候选采用了本目录的框架而加分**，也不得因为不采用而扣分。
   ⚠ 上一版任务书的失败正是反向的同一个毛病：它把「采用 PRD/ADR/TLD」写成扣分项。
4. opus 的候选若与本目录高度重合，**由所有者判断这是独立得出还是自我引用**；
   opus 在自己的候选里必须显式声明哪些结论来自本目录。
