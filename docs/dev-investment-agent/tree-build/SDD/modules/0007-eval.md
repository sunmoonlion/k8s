# `0007-eval` 评测

> 三元组里抄不走的那一角。不在在线路径上。先落 `investment-backend` 的 `eval/`。

## 三道门

| 门 | 判什么 | 何时跑 | `undecidable` 时 |
| --- | --- | --- | --- |
| 数据质量 | 数据集与口径表对金标准 | 数据版本发布前 | 不发布 |
| 专家包发布 | 冻结任务集上四臂（基线 / A / B / C）的质量、引用、费用 | 专家包版本发布前 | 不发布 |
| 单次结果验收 | 一个 Task 的交回物 | 在线，由 `0001` 的验收块调用规则 | Task 进 `WAITING(INPUT)` 交人 |

## 功能义务

| ID | 义务 |
| --- | --- |
| `F-EVAL-01` | 真值定在查询层：`truth_queries`、`result_fingerprint`、`tolerance`；引用数据版本 |
| `F-EVAL-02` | 四臂报告按 Profile 出；费用一列参与判负（`AT-27`） |
| `F-EVAL-03` | 改动后回归：专家包、Profile、数据版本任一变更触发 |
| `F-EVAL-04` | 真实委托的返工、终审改动、验收打回沉淀为样本；另留未见过的任务集 |
| `F-EVAL-05` | 三道门结论只有 `pass` / `fail` / `undecidable`，不折成通过 |
| `F-EVAL-06` | 评测跑在用户以外的账户与 key 上；费用单列 |
