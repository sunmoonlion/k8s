# Architecture v2 R4.1 source topology cleanup

状态：`DONE / R5 MAY START`

日期：2026-08-09

## 1. 目的

在进入 R5 数据迁移前，消除 Info/Knowledge 父仓中仍会误导施工的旧四组件源码：

- 活跃父仓只保留 `admin-frontend + web-frontend + unified backend` 三个子模块；
- 旧 Info Web Backend 从父仓解除，但独立远程历史、冻结标签和镜像继续保留；
- 删除父仓中的 Celery/NodeBull worker 副本、旧 scaffold、init 和四组件说明；
- K8s v1 运行声明保持原状并加明确回滚边界，不触碰当前集群、数据或流量；
- 统一 Backend 的未来 bootstrap 身份改为 `info-backend` / `knowledge-backend`，
  删除仓库内开发密码并用自动测试防止旧身份回流。

## 2. 非目标

本轮不执行 R5，不创建或迁移数据库，不修改 KIND Deployment/Secret/PVC，不删除
Harbor 镜像，也不把候选版本晋级为 `2.0.0`。

## 3. 退出条件

- 两个父仓 `.gitmodules` 各且仅有三个规范子模块；
- 父仓无旧 worker/scaffold/init/Web Backend 活跃源码；
- 两个统一 Backend Ruff、Pyright、全量 pytest、JSON 与 Shell 语法通过；
- GitHub `origin` 与 Gitee `gitee` 的 `architecture-v2` 指向相同提交；
- 本文更新为 `DONE` 并记录最终 commit/测试计数。
