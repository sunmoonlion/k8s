## 二、机制

### 2.1 `sunmoon-agent pair --page`

```text
pair --page
  ├─ 起回环 HTTP：127.0.0.1:<随机端口>，路径带 32 字节随机 nonce
  ├─ 打开默认浏览器：http://127.0.0.1:<port>/setup/<nonce>
  ├─ 照旧建配对请求、每 3 秒轮询（runPair 不变）
  ├─ 进展写内存状态（沿用 pair-status.json 的字段：event、user_code、expires_at、verify_url、status、message、account）
  ├─ approved → 写 config.json → autostart enable → start --background → 等 connected（≤30 秒）
  └─ 页面显示「已在线」+ 下一步；30 分钟后或用户点「完成」后进程退出
```

| 路径 | 方法 | 做什么 |
| --- | --- | --- |
| `/setup/<nonce>` | GET | 一页内联 HTML/CSS/JS（不引外链，离线可用） |
| `/setup/<nonce>/state` | GET | 当前状态 JSON；页面每秒取 |
| `/setup/<nonce>/refresh` | POST | 取消当前请求、重新申请码 |
| `/setup/<nonce>/cancel` | POST | 取消并退出 |
| `/setup/<nonce>/done` | POST | 用户点完成，进程退出 |

安全：只绑 `127.0.0.1`；nonce 不对就 404；检查 `Host` 为 `127.0.0.1:<port>`、`Origin`/`Referer` 为同源或空，拒跨站；响应 `Cache-Control: no-store`、`Referrer-Policy: no-referrer`；状态里永远没有令牌、`device_secret`；进程退出端口即关。浏览器怎么开：`spawn("cmd.exe", ["/c", "start", "", url], { windowsHide: true })`，URL 只含我们生成的字符。

### 2.2 页面上有什么

| 阶段 | 显示 |
| --- | --- |
| 取码中 | 「正在取连接码…」 |
| 有码 | 大字 `XXXX-XXXX`、倒计时、按钮「打开核对页」（新标签开 `verify_url`；第一次自动开）、一句「在核对页里输入这个码并点允许。只有这个码此刻显示在你自己的电脑上时才输」、「重新获取」「取消」 |
| 已允许 | 「已连接到 <账号>」→「正在启动代理…」→「已在线」；失败显示 0012 §4 的人话错误与「重试」 |
| 完成 | 「接下来选文件夹：托盘图标右键 → 白名单与上限设置。不选的话工作和专家碰不到你的文件。」「开机自动运行已打开，可在托盘关闭。」按钮「完成」 |

### 2.5 兜底
