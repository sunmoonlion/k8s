# 开发必须遵守的规则

> 本平台上**所有 agent 开发任务**动代码前都要对照。违反其中任一条的方案**不进入讨论**。
>
> 项目现在长什么样见 [`../../project-guide/`](../../../project-guide)；要建什么见 [`requirement.md`](../PRD/requirement.md)；
> 分期见 [分期与工作量](../../../project-guide/staging.md)。
> 本树 2026-09-23 重写；旧规则在 `../../tree-build-v1/rules/constraints.md`，编号沿用，退役的注明。

## 怎么用

按**你要动什么**取对应的组，把相关条目和结论写出来，两三行的小表：

| 你要动 | 读哪节 |
| --- | --- |
| 表、迁移、存储 | [数据](#数据) |
| 跨 App 接口、契约 | [契约](#契约) |
| 登录、权限、服务间调用、令牌 | [身份](#身份) |
| 仓库、组件、运行角色、站点 | [拓扑](#拓扑) |
| 部署、发版、镜像 | [发布](#发布) |
| 沙箱、执行环境、顾问、专家包 | [智能体](#智能体) |

**「谁在执行」那一栏是重点。**标 ⚠ 的没有自动载体，只能靠自检和评审守住。

### 做数据迁移时

`expand → backfill → reconcile → switch read → switch write → observe → contract`。旧写路径切换必须 fail-closed，不得无期限双写；六条验收缺一不可：可恢复备份加实际恢复演练、回填计数对账、新旧读路径对比、旧凭据被拒、`migration current` 单 head、回滚与重新前滚通过。**这一节无自动载体。**

| C-A10 | **预算硬停首版即有**：每个委托设总预算，覆盖执行、验收、返工、工具费；超限进 `WAITING(RESOURCE)`；追加须用户批准；第一期禁并行 Attempt 与竞争择优 | `AT-12` |

## 设计原则的具体化

`P0`–`P6` 的真源是 [SDD「设计必须满足」](../../turn/sdd/finalize.md)。本项目取值：`P0` 状态机是 Task / Attempt 两层，Profile 不得新增状态词，方向盘是对象属性不是状态词；`P1` 对应 `I5`；`P5` 见"保证这些被遵守的三层"；`P6` 未核前提记在 [待定决策](../decisions.md)。

## 反模式

| 反模式 | 失败方式 |
| --- | --- |
| Task 与 Attempt 合并 | 一次执行失败过早终结用户请求 |
| 先推送后落库 | 用户看见无法回放的幽灵事件 |
| 用户与顾问同时发 turn | 同一 thread 两个写入者，产物互相覆盖 |
| 执行环境断了改在沙箱里跑 | 工具跑在错的机器上，静默 |
| 云端能提高本地沙箱权限 | 云端被攻破等于每台用户机器被远程控制 |
| 边缘存业务状态 | 边缘一坏数据跟着丢；边缘被攻破拿到数据 |
| 内网开入站端口 | 拓扑不变量失效 |
| 同幂等键异载荷静默复用 | 用户得到另一请求的结果 |
| 顾问自行加步、加预算 | 用户账单失控 |
| 方法库写入买卖标准 | 系统替用户下判断 |
| 把 Codex thread 当 Task 真源 | 两个真源 |
| 规范只有文字没有测试映射 | 「必须」无法执行 |
