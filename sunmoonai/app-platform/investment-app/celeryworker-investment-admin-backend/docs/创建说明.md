# celeryworker-investment-admin-backend 创建说明

## 定位

该目录是 `investment-app` 内置的 Celery Worker 模板实例，服务 `investment-admin-backend` 的异步任务。

执行 `init.sh <app-name>` 后会变为：

```text
celeryworker-<app-name>-admin-backend
```

## 配置关系

- Worker 默认镜像：`harbor.sunmoonai.com:30443/k8s-images/investment-admin-backend:1.0.0`
- 业务配置来源：`investment-admin-backend-config`、`investment-admin-backend-secret`
- Worker 自身配置：`celeryworker-investment-admin-backend-config`、`celeryworker-investment-admin-backend-secret`
- 队列：`investment.admin.default`

`init.sh` 会把文件内容和路径中的 `investment` 一并替换成目标应用名。

数据库、Neo4j、Redis 等业务连接不在 Worker 中重新维护，继续复用 `investment-admin-backend` 的 ConfigMap/Secret。

## RabbitMQ

`declare-rabbitmq-queue` initContainer 会用 `CELERY_BROKER_URL` 声明 `CELERY_QUEUE`。RabbitMQ 用户、密码、vhost 和权限需要由 RabbitMQ 组件或运维侧提前提供。
