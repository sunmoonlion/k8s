## 二、改钉与迁移号

只改 `infrastructure/applications/sources.yaml` 的 **investment 块里五个键**（`parent_revision`、`backend_parent_revision`、`backend_revision`、`web_parent_revision`、`web_revision`；`admin_*` 两行不动、别的应用不动）和 `config.yaml` 的两行。用下面的脚本或手改都行（上一张卡的脚本按 `\n  ` 截块会误伤四空格缩进，这次按「下一个两空格顶格键」截）：

```bash
python3 - <<'PY'
import re,pathlib
p=pathlib.Path('infrastructure/applications/sources.yaml'); s=p.read_text()
m=re.search(r'(?ms)^  investment:\n(?:(?!^  \S).*\n?)*', s)
assert m, 'investment block not found'
block=m.group(0)
new=block
new=re.sub(r'(?m)^(    parent_revision: )\w+', r'\g<1>347e17a8669c618d2669c36921ee7638dc206b76', new, count=1)
new=re.sub(r'(?m)^(    backend_parent_revision: )\w+', r'\g<1>8d9bdd20ccd577f09de2a7a924e20193531145c0', new)
new=re.sub(r'(?m)^(    backend_revision: )\w+', r'\g<1>8d9bdd20ccd577f09de2a7a924e20193531145c0', new)
new=re.sub(r'(?m)^(    web_parent_revision: )\w+', r'\g<1>c981e3a870741da39c47f8df04f37347ad65862d', new)
new=re.sub(r'(?m)^(    web_revision: )\w+', r'\g<1>c981e3a870741da39c47f8df04f37347ad65862d', new)
assert new!=block, 'nothing changed'
p.write_text(s.replace(block,new,1))
c=pathlib.Path('gitops/components/app-platform/investment-app/investment-backend/config.yaml'); t=c.read_text()
t2=t.replace('migration_job_revision: v5','migration_job_revision: v6').replace("expected_schema_revision: '20261012_0016'","expected_schema_revision: '20261012_0017'")
assert t2!=t, 'config unchanged'
c.write_text(t2)
PY
git diff --stat; git diff infrastructure/applications/sources.yaml gitops/components/app-platform/investment-app/investment-backend/config.yaml | grep "^[-+]" | grep -v "^+++\|^---"
```

要看到：只动这两份文件；investment 五个 revision 换成上面三个提交；`v6` / `'20261012_0017'`；管理端那两行不变。
