# celeryworker-tools-admin-backend 创建说明

## 定位

该目录是 `tools-app` 内置的 Celery Worker 模板实例，服务 `tools-admin-backend` 的异步任务。

执行 `init.sh <app-name>` 后会变为：

```text
celeryworker-<app-name>-admin-backend
```

## 配置关系

- Worker 默认镜像：`harbor.sunmoonai.com:30443/k8s-images/tools-admin-backend:1.0.0`
- 业务配置来源：`tools-admin-backend-config`、`tools-admin-backend-secret`
- Worker 自身配置：`celeryworker-tools-admin-backend-config`、`celeryworker-tools-admin-backend-secret`
- 队列：`tools.admin.default`

`init.sh` 会把文件内容和路径中的 `tools` 一并替换成目标应用名。

数据库、Neo4j、Redis 等业务连接不在 Worker 中重新维护，继续复用 `tools-admin-backend` 的 ConfigMap/Secret。

## RabbitMQ

RabbitMQ vhost、用户、权限和队列由 `messaging-platform/rabbitmq` 的 app definitions 统一创建；Worker 只使用受限 worker 用户连接并消费 `CELERY_QUEUE`。
