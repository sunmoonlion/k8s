# nodebullworker-llm-web-backend 创建说明

## 定位

该组件对应 `tpl-app/nodebullworker-tpl-web-backend` 模板实例化后的结果，作为 Node Bull Worker 服务 `llm-web-backend` 的异步任务。

当前 `web-backend` 是 Node.js 技术栈，Worker 使用同一个 web-backend 镜像，通过 `node dist/worker` 启动 Nest application context，并消费 Bull 队列。

## 配置关系

- Worker 默认镜像：`harbor.sunmoonai.com:30443/k8s-images/llm-web-backend:1.0.0`
- 业务配置来源：`llm-web-backend-config`、`llm-web-backend-secret`
- Worker 自身配置：`nodebullworker-llm-web-backend-config`、`nodebullworker-llm-web-backend-secret`
- Bull 队列：`scheduled-tasks`

数据库、Neo4j、Redis 等业务连接不在 Worker 中重新维护，继续复用 `llm-web-backend` 的 ConfigMap/Secret。

## 队列

`web-backend` 当前使用 NestJS Bull + Redis。Worker 复用 backend 的 ConfigMap/Secret 获取业务数据库等配置，同时额外挂载 `*-nodebull-redis-conn` 获取 `QUEUE_REDIS_*` 队列 Redis 配置，并在启动时设置 `QUEUE_ON=true` 来注册队列消费者。RabbitMQ 配置不参与该 Node Worker 的运行。
