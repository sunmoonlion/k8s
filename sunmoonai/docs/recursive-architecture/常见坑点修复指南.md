# 递归部署架构常见坑点修复指南

## 概述

本文档记录了递归部署架构开发过程中遇到的常见问题和修复方案，帮助开发人员快速定位和解决问题。

## 1. 路径问题

### 问题描述
部署脚本运行时提示配置文件路径错误。

### 错误信息
```bash
[ERROR] 缺少 Harbor 配置文件: ~/k8s/utils/deploy-harbor-all.conf
```

### 根本原因
统一部署模板重新定义了 `SCRIPT_DIR` 变量，覆盖了脚本中的路径变量。

### 修复方案
```bash
# 保存原始路径
HARBOR_SCRIPT_DIR="$SCRIPT_DIR"

# 导入统一部署模板
source "$PROJECT_ROOT/../../../utils/unified-deployment-template.sh"

# 恢复正确路径
SCRIPT_DIR="$HARBOR_SCRIPT_DIR"
```

### 详细说明
参考：[路径修复指南](./path-fix-guide.md)

## 2. 变量引用错误

### 问题描述
脚本运行时出现未定义变量错误。

### 错误信息
```bash
./deploy-harbor-all.sh: line 335: name_enabled: unbound variable
```

### 根本原因
在循环中使用了未定义的变量 `$name_enabled`，但实际应该使用 `${name}_enabled`。

### 修复前
```bash
log_info "⏭️  跳过 $description 部署 ($name_enabled=false)"
```

### 修复后
```bash
log_info "⏭️  跳过 $description 部署 (${name}_enabled=false)"
```

### 预防措施
- 使用 `set -u` 启用未定义变量检查
- 在循环中明确变量作用域
- 使用 `${variable}` 语法确保变量正确解析

## 3. 配置文件缺失

### 问题描述
脚本无法找到配置文件。

### 错误信息
```bash
[ERROR] 缺少 Harbor 配置文件: /path/to/config.conf
```

### 常见原因
1. 配置文件路径错误
2. 配置文件不存在
3. 权限问题

### 修复方案
```bash
# 检查配置文件是否存在
if [[ -f "$CONFIG_FILE" ]]; then
    source "$CONFIG_FILE"
    log_info "已加载配置文件: $CONFIG_FILE"
else
    log_error "缺少配置文件: $CONFIG_FILE"
    exit 1
fi
```

## 4. 统一部署模板导入失败

### 问题描述
无法导入统一部署模板。

### 错误信息
```bash
source: /path/to/unified-deployment-template.sh: No such file or directory
```

### 修复方案
```bash
# 检查统一部署模板是否存在
if [[ -f "$PROJECT_ROOT/../../../utils/unified-deployment-template.sh" ]]; then
    source "$PROJECT_ROOT/../../../utils/unified-deployment-template.sh"
else
    log_error "统一部署模板不存在: $PROJECT_ROOT/../../../utils/unified-deployment-template.sh"
    exit 1
fi
```

## 5. Kubernetes 连接问题

### 问题描述
无法建立 Kubernetes 连接。

### 错误信息
```bash
[ERROR] 无法建立 Kubernetes 连接
```

### 常见原因
1. 配置文件路径错误
2. 网络连接问题
3. 认证问题

### 修复方案
```bash
# 检查 kubectl 是否可用
if ! command -v kubectl &> /dev/null; then
    log_error "kubectl 未安装"
    return 1
fi

# 设置 Kubernetes 环境
if ! setup_kubectl_environment; then
    log_error "无法建立 Kubernetes 连接"
    return 1
fi
```

## 6. 子级组件脚本不存在

### 问题描述
子级组件部署脚本不存在。

### 错误信息
```bash
[WARN] ⚠️  Traefik 中间件 部署脚本不存在: /path/to/script.sh
```

### 修复方案
```bash
# 检查脚本是否存在
if [[ -f "$script_path" ]]; then
    # 执行脚本
    ./"$(basename "$script_path")" "$project_id" "$namespace" "$environment" "$dry_run"
else
    log_warn "⚠️  $description 部署脚本不存在: $script_path"
    # 可以选择跳过或退出
fi
```

## 8. 环境变量未设置

### 问题描述
必需的环境变量未设置。

### 错误信息
```bash
[ERROR] 配置文件缺少必需字段: HARBOR_PROJECT_ID
```

### 修复方案
```bash
# 检查必需的环境变量
local required_vars=(
    "HARBOR_PROJECT_ID"
    "HARBOR_NAMESPACE"
    "ENVIRONMENT"
    "HARBOR_EXTERNAL_HOST"
    "HARBOR_EXTERNAL_PORT"
)

for var in "${required_vars[@]}"; do
    if [[ -z "${!var:-}" ]]; then
        log_error "配置文件缺少必需字段: $var"
        return 1
    fi
done
```

## 9. 循环变量作用域问题

### 问题描述
循环中的变量在循环外无法访问。

### 错误信息
```bash
[ERROR] 变量未定义
```

### 修复方案
```bash
# 在循环前声明变量
local components=()
local sorted_components=()

# 在循环中使用 local 声明
for component_info in "${sorted_components[@]}"; do
    local name enabled priority description script_path
    IFS=':' read -r name enabled priority description script_path <<< "$component_info"
    # 使用变量
done
```

