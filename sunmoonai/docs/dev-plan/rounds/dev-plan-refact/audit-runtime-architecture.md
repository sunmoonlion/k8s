## 判定口径

按所有者的定调，**「抵触」不算缺**。四类：

| 类 | 含义 | 计不计缺 |
| --- | --- | --- |
| 已落地 | 内容在 guide 里，措辞可不同 | 否 |

| 抵触 | guide 有相反主张 | **否**——以 guide 为准 |
| **★ 真缺** | guide 里找不到，也没有撤销记录 | **是** |

## 四、取证方法与一处自证

判定用两轮探针 + 逐节读正文。**第一轮探针给过假答案**：
`grep -cE 'RECEIVED *→ *VALIDATING'` 在 guide 命中 1，被读成「合法转换全集在」——
实际命中的是 §3.3 投影表里的一格。**假阳与假阴各出过一次**，
故最终结论以读正文为准，探针只用于定位。

零命中一律回读原文确认，不直接判缺——这是协议 §8.1「零命中要能区分『真的没有』与『没查到』」。
