## 备注

- `R4` / `R5` 与 `round-status.py` 的 `all({})` 是**同一条纪律的三次触发**：
  **检查在边界条件下不报错，而是给出一个看起来像结论的东西**，下游据此继续推理。
  `all({})` 报「完成」，判别命令吐 `.`，产品映射句被当成身份证据——三次都不是「查漏了」，
  是「查出了一个假答案」。按「裁量是规则的孵化器」，第三次即达升级门槛：
  **本轮 ⑦ 清理时须把这条提为 `round-protocol` 的正式纪律**，不再留在轮次 rulings 里。

  身份只能有一个来源，其余全部应显式标为「不是证据」。
