## 一、标题

财务分析与预测

## 二、六问

**1. 解决什么**

对一家中国 A 股上市公司，用我上传的财报（三张表与年报）：先核数据（勾稽、对照年报披露），再把问题点到的科目和一组固定的核心指标算出来、看清走势；再对营业收入、归母净利润（问题点名的再加别的流量科目）做预测，每个预测都先回测，再给区间和假设。〔U1、U2、U5、G0〕

**2. 不解决什么**

不逐科目预测整套报表（三张表配不平，配平要三表联动模型，接近估值，超出边界）；比率不单独外推，由预测出的收入与利润推算。〔U2〕数据里没有的不硬算、不冒充，照实说算不出来。〔U3〕只做 A 股上市公司。〔U1〕不评价好坏、不下结论，不给买卖建议、评级、目标价。〔G9；平台规矩〕

**3. 输入是什么**

我上传的数据。〔U4〕每家公司一份 Excel：三张表（资产负债表、利润表、现金流量表），合并报表，按报告期累计数（一季报、半年报、三季报、年报），近 5 年，单位元；再加一张「主要会计数据」，抄年报上的那几项；另传对应年度的年报 PDF，用于对照官方披露。〔G1；「主要会计数据」那张，所有者「按建议」〕

**4. 步骤与每步的判断规则**

八步，按顺序：〔G0〕

1. **定范围**：问题里的公司不在我的数据里，就停下说明，不去别处找；同一个科目有两个口径（例如合并与母公司混在一起），问我用哪个。〔G11〕
2. **数据摸底**：列出我的数据里有哪些表、哪些报告期、哪些科目；期数不够做后面的回测或预测，能做的照做、写明原因。〔G11〕
3. **勾稽**：查四条——资产总计 = 负债合计 + 所有者权益合计；归母净利润 + 少数股东损益 = 净利润；现金流量表 期末现金 = 期初现金 + 现金净增加额；本期期初 = 上期期末（我的表只有期末数，这一条用现金流量表查：今年年报的期初现金及现金等价物余额 = 去年年报的期末现金及现金等价物余额）。差额超过 1 元算不平；不平照实列出、写进局限，继续往下做，不平的期不进预测窗口。〔G2；第 4 条怎么查，所有者「按建议」〕
4. **取数**：利润表、现金流量表的累计数换成单季：Q1 = 一季报；Q2 = 半年报 − 一季报；Q3 = 三季报 − 半年报；Q4 = 年报 − 三季报。资产负债表是时点数，不换算。〔G3〕
5. **算指标与分析**：分析的科目 = 问题点到的科目 + 固定核心指标（营业收入、归母净利润、扣非净利润、经营现金流；毛利率、净利率、净资产收益率、经营现金流与净利润之比、收入与利润增速）。〔U2〕口径：毛利率 =（营业收入 − 营业成本）/ 营业收入；净利率 = 归母净利润 / 营业收入；净资产收益率 = 归母净利润 / 平均归母净资产（期初期末平均；季度不年化，年度用全年）；经营现金流与净利润之比 = 经营活动现金流量净额 / 归母净利润；收入与利润增速 = 同比（与上年同期比）。〔G4〕分母为 0、为负或缺数时，这个指标标「不适用」并写原因，不算。〔G5〕只描述，不评价好坏。〔G9〕
6. **对照官方披露**：年报「主要会计数据和财务指标」的数我抄在表格的「主要会计数据」那张工作表里，先读年报 PDF 核对这张表抄得对不对、写明页码；再拿三张表里的营业收入、归母净利润、扣非净利润、经营现金流和它比：相对差超过 0.1% 算对不上，两个数都列出，成稿以年报披露为准并提醒；加权平均净资产收益率和第 5 步的净资产收益率口径不同（年报加权平均，本方法期初期末平均），两个数并列、注明口径不同，不判对得上对不上。〔G6，所有者「按建议」两次〕
7. **预测**：只预测营业收入、归母净利润（问题点名的再加别的流量科目）；比率由预测出的收入与利润推算。〔U2〕方法用季节性同比：下一季度 = 上年同季单季值 ×（1 + 最近 4 个季度同比增速的中位数）；区间 = 用最近 8 个季度同比增速的最小值、最大值代替中位数算出的上下限；假设至少两条（近期增速延续；没有重大口径或业务变化）。〔G7〕先回测：拿最近 4 个季度，每季只用当时之前的数据按同一方法预测，报每季的相对误差、平均误差、落进区间的个数；季度不够 12 个不回测、写明原因。最多预测 4 个季度。〔G8〕
8. **成稿**：见第 5 问。〔G9〕

**5. 输出长什么样**

一篇 Markdown，依次是：回答 → 数据（每个数带出处：文件、表、行、期）→ 勾稽与对照的结果 → 指标与发现（只描述，不评价好坏）→ 预测表（方法、回测、区间、假设）→ 局限 → 出处。结论栏留空。〔G9〕

**6. 怎样算对**

数据里没有的照实说「算不出来」，不硬算、不冒充。〔U3〕每个预测都带回测、区间与假设。〔U2、G8〕勾稽、对照官方的结果照实列出，对不上的不藏。〔G2、G6〕具体的验收用例见下面填的三条。〔G10〕
