## ⚠️ 需要确认的配置

1. **数据库连接参数**
   - 当前配置：`DB_HOST="postgresql-service.data-platform"`, `DB_NAME="app"`, `DB_PORT="5432"`
   - 需要确认：数据库用户名和密码是否正确（当前使用 `sunmoonai_dev` / `zym123`）

2. **队列名称**
   - 当前配置：`llmops-queue`
   - 需要确认：`llmops-app-backend` 发送任务时使用的队列名称是否为 `llmops-queue`

3. **镜像标签**
   - 当前配置：`BACKEND_TAG="1.0.0"`
   - 需要确认：`llmops-app-backend` 的实际镜像标签版本

4. **Redis 数据库编号**
   - 当前配置：数据库 `0`
   - 需要确认：是否使用数据库 0（incubator 使用数据库 10）
