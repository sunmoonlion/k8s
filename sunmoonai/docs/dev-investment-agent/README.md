# `dev-investment-agent/` 目录

**开发 investment-app 那个 agent 所需要的全部。**

这个 agent 要做的事,是把[一次 turn 的九站](pipeline.md)从人手里一格一格接过去。
它的专业领域是投资,但**树上每个节点的题目都是「某一环节怎么脚本化」,不是投资业务怎么做**。

| | 是什么 |
| --- | --- |
| [`pipeline.md`](pipeline.md) | **主干**:九站、每一站现在谁做(人还是脚本)、走完的判据。两边都指它 |
| [`turn/`](turn/README.md) | **一次一问一答怎么走完**:问什么、怎么答、怎么定稿、怎么验、谁批、派几家 |
| [`tree-build/`](tree-build/README.md) | **把九站一格一格改成脚本的那棵树**:要建什么、切成哪些块、每块的定稿与委托记录 |
| [`tools/`](tools/README.md) | 门禁脚本,由 `.githooks/` 在提交与合并前调用 |
| [`switch-test/`](switch-test/README.md) | **换机测试**:远程写代码、本地跑测试的约定与模板;输出落 `scripts/results/` 进 git,不贴对话 |

⚠ **本目录之外的不归这里**:平台现状(五个仓)在 [`../project-guide/`](../project-guide/README.md),
运维笔记散在 `docs/` 根下。

## 别的项目要用怎么办

`turn/` 与 `pipeline.md` 的九站**本身不绑定投资**——换个项目、换个领域,规矩照样成立。
但它们放在这里,因为现在只有这一个项目用。

**别的项目要用,就复制一份过去。**⚠ **复制即分叉**:两份从复制那一刻起各自演进,
**不再互为真源**,谁也不必跟谁同步。要引用对方的条款,写清是哪一份的哪一条。

⚠ **不要跨目录引用**——`../<别的项目>/turn/...` 这种链接会让两份看起来还是一份,
而它们已经不是了。
