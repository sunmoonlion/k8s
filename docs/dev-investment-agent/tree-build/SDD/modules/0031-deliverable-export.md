# 成稿与表格导出：Word、Excel、PDF（0031）

> 状态：**已定，实施中**。所有者 2026-10-17：「我看到workbuddy里的专家都将表格整理成excel文件，我们的查询财报时能不能最好把三大表也整理成excel文件？」「有时还有转word文档，txt太难看了，能做吗」「或者pdf」；Opus 提三个按钮的做法，所有者「按你建议」，排在 0030 的小发布一起上或紧随其后。Opus 起草。

## 一、要解决什么

专家的成稿与工作对话交回的文件都是 Markdown（`.md`），用记事本打开满是 `#`、`|`、`**`；表格要接着算时只能手抄进 Excel。

## 二、做法

工作台网页在「结果」边栏与底稿里打开 `.md` 文件时，旁边给三个按钮：

| 按钮 | 得到什么 | 怎么生成 |
| --- | --- | --- |
| 下载 Word | `.docx`：标题分级、段落、列表、加粗、链接、代码，Markdown 表格转成 Word 表格；中文字体设好 | 浏览器里转（`docx` 库） |
| 下载 Excel | `.xlsx`：文件里每张 Markdown 表格一张工作表（表名取表格前最近的标题），能读成数的格子存成数；最后一张「出处」写文件路径、导出时间 | 浏览器里转（`exceljs` 库） |
| 导出 PDF | 打开干净的打印视图（去掉侧栏与按钮、表格不跨页断行、页眉写文件名），弹出打印框，选「另存为 PDF」 | 浏览器打印 |

**在浏览器里转、不经后端**：网页本来就是经本机的代理直接读这台电脑上的文件（`/local/v1/fs/file`），后端拿不到文件内容；在浏览器里转，文件不离开用户的电脑，后端不加东西、镜像不变。两个库只在点按钮时才加载，不拖慢页面。

**数从哪来要说清**：导出只是把**文件里已有的内容**换个格式，不另取数、不改数。成稿里的数是专家（模型）照工具结果写的——分身用 0030 的计算工具与数值验收守数准；内置专家目前靠方法与结构验收，数值验收以后再扩到内置专家。Excel 里的数与成稿逐格一致。

**三大表**：Excel 只能导出成稿里已有的表。要拿到完整的三大表，内置专家「中国A股上市公司财务分析与预测」的成稿要加一节附表（取到的各报告期的资产负债表、利润表、现金流量表）——这是方法包的工程化，另记（见第四节）。

## 三、不做的

- 不在服务器上生成 PDF（要装排版引擎与中文字体，镜像变大）；真要自动生成再议。
- 这一版不自动把导出的文件写进项目目录（要代理能写二进制文件，先核）；先做下载。
