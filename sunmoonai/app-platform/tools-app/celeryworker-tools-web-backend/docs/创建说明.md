# celeryworker-tools-web-backend 创建说明

## 定位

该目录是 `tools-app` 内置的 Celery Worker 模板实例，服务 `tools-web-backend` 的异步任务。

执行 `init.sh <app-name>` 后会变为：

```text
celeryworker-<app-name>-web-backend
```

## 配置关系

- Worker 默认镜像：`harbor.sunmoonai.com:30443/k8s-images/tools-web-backend:1.0.0`
- 业务配置来源：`tools-web-backend-config`、`tools-web-backend-secret`
- Worker 自身配置：`celeryworker-tools-web-backend-config`、`celeryworker-tools-web-backend-secret`
- 队列：`tools.web.default`

`init.sh` 会把文件内容和路径中的 `tools` 一并替换成目标应用名。

数据库、Neo4j、Redis 等业务连接不在 Worker 中重新维护，继续复用 `tools-web-backend` 的 ConfigMap/Secret。

## RabbitMQ

`declare-rabbitmq-queue` initContainer 会用 `CELERY_BROKER_URL` 声明 `CELERY_QUEUE`。RabbitMQ 用户、密码、vhost 和权限需要由 RabbitMQ 组件或运维侧提前提供。
