# 样本 · 第 2 步：要回问用户的缺口

> 用户（所有者）逐条答。每条都给了我们的**提议**，方便答「按提议」；答了的，清单里那条规则的出处写 `user_confirmed` 加答复原话。投资判断只有用户能定，我们不替他定（`C-L1`）。工程化的事（步骤怎么切、交回物格式、验收怎么写、额度）不在这里问，见 [`03-engineering.md`](03-engineering.md)。

| 号 | 问什么 | 我们的提议 | 为什么要问 |
| --- | --- | --- | --- |
| G0 | 步骤顺序与要不要这几步 | 定范围 → 数据摸底 → 勾稽 → 取数（季报累计换算单季）→ 算指标与分析 → 对照官方披露 → 预测 → 成稿（八步，即 10-15 的流程草案） | 10-15 的草案是 Opus 的「拟为」，没有逐条确认；勾稽、对照官方是不是你的方法要你说 |
| G1 | 你上传什么数据 | 每家公司一份 Excel 或 CSV：三张表（资产负债表、利润表、现金流量表）**合并报表**、**按报告期累计数**（一季报、半年报、三季报、年报），近 5 年，单位元；另传对应年度的年报 PDF（用于对照官方披露） | 分身只能读你上传的（U4）；格式定了，取数与换算才写得死 |
| G2 | 勾稽查哪几条，不平怎么办 | 查四条：资产总计 = 负债合计 + 所有者权益合计；归母净利润 + 少数股东损益 = 净利润；现金流量表 期末现金 = 期初现金 + 现金净增加额；本期期初 = 上期期末（资产负债表主要科目）。差额超过 1 元算不平；**不平照实列出、写进局限，继续往下做，不平的期不进预测窗口** | 这些是会计恒等式，但查不查、不平时停不停是你的判断 |
| G3 | 季报累计数怎么换成单季 | 利润表、现金流量表：Q1 = 一季报；Q2 = 半年报 − 一季报；Q3 = 三季报 − 半年报；Q4 = 年报 − 三季报。资产负债表是时点数，不换算 | 换算规则决定每个单季的数 |
| G4 | 核心指标的口径 | 毛利率 = (营业收入 − 营业成本) / 营业收入；净利率 = 归母净利润 / 营业收入；净资产收益率 = 归母净利润 / 平均归母净资产（期初期末平均；季度不年化，年度用全年）；经营现金流与净利润之比 = 经营活动现金流量净额 / 归母净利润；收入与利润增速 = 同比（与上年同期比） | U2 只给了指标名；分子分母、平均还是期末，结果可以差很多 |
| G5 | 分母不成立时 | 分母为 0、为负或缺数时，这个指标标「不适用」并写原因，不算 | 你说过「不硬算、不冒充」（U3），这里要你确认落到指标上就是这样 |
| G6 | 对照官方披露对哪几项、差多少算对不上 | 对照年报「主要会计数据和财务指标」里的营业收入、归母净利润、扣非净利润、经营现金流、加权平均净资产收益率；相对差超过 0.1% 算对不上；对不上的两个数都列出，成稿以年报披露为准并提醒 | 对照的范围和容差是你的判断 |
| G7 | 预测用什么方法 | **季节性同比法**：下一季度 = 上年同季单季值 × (1 + 最近 4 个季度同比增速的中位数)；区间 = 用最近 8 个季度同比增速的最小值到最大值代替中位数算出的上下限；假设至少两条（近期增速延续、没有重大口径或业务变化）。你若有自己的方法，就按你的 | U2 只说「各自回测、各给区间与假设」，没说方法。第 2 版的移动平均是 Opus 定的，而且不带季节性 |
| G8 | 回测与预测期数 | 回测：拿最近 4 个季度，用当时之前的数据按同一方法预测，报每季的相对误差与平均误差、落进区间的个数；季度不够 12 个不回测、写明原因。最多预测 4 个季度 | 回测的做法与期数上限是你的判断 |
| G9 | 成稿长什么样 | 按「回答 → 数据（每个数带出处：文件、表、行、期）→ 勾稽与对照的结果 → 指标与发现（只描述，不评价好坏）→ 预测表（方法、回测、区间、假设）→ 局限 → 出处」写一篇 Markdown；结论栏留空（财报体检原来的做法） | 你没说过成稿的样子；结论栏留不留是你的选择 |
| G10 | 验收用例 | 三条：① 「贵州茅台近三年的营业收入和归母净利润走势如何？预测下两个季度。」期望：对照官方那一步里 2024 年营业收入与年报一致（approx，容差 0.1%，值由你从年报填）；预测里有两个季度。② 「贵州茅台近三年的研发费用率」——如果你的数据里没有研发费用，期望结果写明「算不出来」。③ 问一家你没上传数据的公司，期望在定范围就停下说明没有数据 | 「怎样算对」只有你能定；期望值要来自你（年报上的数） |
| G11 | 什么时候停下来问你 | 问题里的公司不在你的数据里 → 停下说明，不去别处找；期间不够回测或预测 → 照做能做的、写明原因；同一个科目有两个口径（例如合并与母公司混在一起）→ 问你用哪个 | 停不停、问不问是你的偏好 |
