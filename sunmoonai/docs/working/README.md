# 怎么共事

> 最后更新：2026-08-29

**本目录管的是协作机制,不是项目内容。**判据很简单——
**改了这里的东西,代码不用动。**

| 文件 | 什么时候读 |
| --- | --- |
| [`request-lifecycle.md`](request-lifecycle.md) | 要提一个开发请求时 |
| [`collaboration.md`](collaboration.md) | 拉取、推送、跨机同步时；子模块的坑都在这 |
| [`doc-conventions.md`](doc-conventions.md) | 改 `../project-guide/` 里任何文档时 |

## 与另外两个目录的分工

| 目录 | 管什么 | 改了之后 |
| --- | --- | --- |
| [`../project-guide/`](../project-guide/) | **项目是什么** | 只是描述变了（因为代码先变了） |
| [`../dev-plan/`](../dev-plan/) | **代码要符合什么、接下来建什么** | **代码要跟着改** |
| 本目录 | **我们怎么共事** | 协作方式变，代码不变 |
