## 归档件怎么用

- **无规范效力。** 与现行文档冲突时以现行文档为准；
- **可以引用为「当时的判断与取证」**，引用时注明是归档件；
- **不参与轮次**：不作为候选、评审或验收的取件对象，也不计入落点表；
- **内容不再修改**。移入时只重定位了相对链接（各 4 处 / 2 处，行数未变），
  正文一字未动；未移入前的字节副本在 `@ ceb7291c`。

## 引用它们的锚点怎么办

删除或移动被引用的文档会让 `` `文件.md:行` `` 这类纯文本锚点失效，而
`doc-gate.py` 只查 markdown 链接，**查不出这一类**（`anchor-gate.py` 就是为此建的）。
本次移动前，活文档里 5 处裸路径锚已改为钉版锚 `@ ceb7291c:<行>`；
`rounds/**` 内的 111 处按归档软判，不改——归档是冻结的历史记录，
锚点按成文时状态解析。
