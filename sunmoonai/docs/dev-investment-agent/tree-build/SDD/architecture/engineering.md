## 共同约束

- 状态机只有一套，场景差异只体现在 Profile 与专家包（`P0`）；
- 同一事实只有一个权威写入面（`P1`）；Codex thread 不是真源；
- 跨进程仍须正确的不变量由 PostgreSQL 承担，不放在沙箱或代理进程里；
- 执行引擎租用不自建，只经 app-server 与 exec-server 的公开协议（`C-A4`、`C-C7`）；
- 接口契约单一真源：网页与代理都从工作台的 OpenAPI 生成客户端；
- 版本成对：Codex 版（app-server 与 exec-server 同版）、会合点协议版、代理版随发布清单钉（`C-R8`）；不匹配拒绝连接（`AT-28`）；
- 领域概念不进 Port 签名（`C-A5`）。

### 细则：后端

三个后端（info、knowledge、investment）和模板（tpl-app）是同一套骨架，规则相同。

| 层 | 目录 | 放什么 | 可以引用 |
| --- | --- | --- | --- |
| 领域 | `app/domain/` | 业务对象、规则、错误。不碰数据库、网络、文件 | 只有标准库和自己 |
| 端口 | `app/application/ports/` | 应用层需要外界做的事，写成接口（`Protocol`） | 领域 |
| 应用 | `app/application/` | 用例与流程 | 领域、端口 |
| 基础设施 | `app/infrastructure/` | 端口的实现：数据库、对象存储、HTTP、PDF、消息队列 | 领域、端口 |
| 接口 | `app/interfaces/` | HTTP 路由、MCP、请求与响应的格式 | 应用、领域 |
| 组装 | `app/bootstrap/` | 把实现接到用例上。**只有这里可以同时引用应用层和基础设施层** | 全部 |
| 命令行 | `app/cli/` | 运维命令 | 组装 |
| 后台任务 | `app/tasks/` | 队列任务的入口 | 组装 |

四条硬规则：

1. **领域层不引用任何外层。**
2. **应用层不引用基础设施层。** 要用数据库或外部服务，先在端口里写接口，实现放基础设施层，在组装里接上。
3. **接口层按「面」分**（`http/admin`、`http/web`、`http/internal`），因为鉴权的边界是按面划的。`interfaces/endpoints/` 是旧的放法，新路由不再往里放。
4. **应用层与领域层不直接引用数据库、网络、消息这类库**（`sqlalchemy`、`sqlite3`、`httpx`、`websockets`、`redis`、`celery`、`fastapi` 等，清单在各后端 `app/pyproject.toml`）。2026-09-29 所有者定加。理由：有的代码没有引用基础设施层，但自己就是基础设施，前三条挡不住。

## 走向企业级：先补的三件（2026-09-26 所有者定）

现状：发布纪律、最小权限、密钥处理、身份这几样已按企业级做（钉摘要的镜像、备份与两次隔离恢复的门禁、列级数据库授权、非 root、只放行需要的出站、ES256 令牌与吊销、bcrypt、邀请码与邮箱验证）。整体仍是"企业级底座上的内测版"。下面三件按顺序补，是上线服务真实用户之前的底线；前端设计与 Windows 安装包是另一条线（能不能用），不在这里。

### 一、端到端自动测试

**为什么先做它**：2026-09-25 到 26 在 KIND 里靠人点浏览器找出的问题——事件流带事件名被浏览器丢掉、只写库的事件不实时、key 列表被严格校验拒收、页面 401 无反应、沙箱模板权限、代理互踢——单元测试全绿，都是跨进程、跨仓的契约与部署问题，端到端测试本来能提前挡住。

- **范围（第一刀）**：真浏览器（Playwright，网页仓已有）驱动一套完整栈，跑下面这些路径：登录 → 设置页登记 key（列表出现）→ 拉起沙箱 → 新建会话发一句话（**不刷新**出现回答）→ 问专家 SMOKE（**不刷新**出现委托卡与状态）→ 打开底稿；换代理令牌（旧代理被断开、新命令能接入）；未登录访问设置页（出现"请重新登录"）。
- **栈怎么起**：沿用正式开发包，在一个一次性的 KIND（或本地 KIND 的独立命名空间）里部署；模型调用用一个假的 OpenAI 兼容服务（回放固定回答），不花钱、不依赖外网；本地代理与会合点用真的。
- **契约防漂移**：前端从后端 OpenAPI 生成客户端（`F-WEB-06`，现在是手写 zod），生成物与后端路由在同一次检查里比对；已先加了两处钉字段的测试（凭据列表、事件帧），这是过渡办法。
- **验收**：上面每条路径一个用例；在 CI 里每次合并前跑；故意把 2026-09-26 修过的任何一个问题改回去，至少一个用例变红。
