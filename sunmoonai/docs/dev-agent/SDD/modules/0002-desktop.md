# 0002-desktop：桌面应用

**承担**：用户**唯一的工作界面**。提交 Task、看进度与结果、任务历史、研究底稿查看与编辑、
本地知识库管理、Task 级审查、工具级审批与本地确认、key 与模型配置、工作区授权、设备与计费；
拉起 runtime 并确保它在跑；托盘、通知、开机启动。

**不承担**：

- 不持有领域事实；
- **不自己调用模型**；
- **不自己开用户的文件**：类别预填由 runtime 经 ③ 算出，这里只呈现、由用户确认或改正；
- **审查窗口不挂本机能力**——它展示的内容来自后端，外来内容加本机能力就是提权路径；
- 不负责 runtime 的存活与崩溃重启，那归系统的服务管理器。

**跑在**用户电脑上。**信任域**：碰不到 key，也碰不到结果正文以外的执行能力。

**三扇独立窗口，能力按窗口授予**——窗口就是能力边界：

| 窗口 | 装什么 |
| --- | --- |
| 主窗口 | 提交 Task、进度与结果、任务历史、本地知识库管理、研究底稿 |
| 本地窗口 | 工具级审批、本地确认、key 与模型配置、工作区授权、runtime 状态 |
| **审查窗口** | Task 级审查。**装的是来自后端的外来内容，因此不挂任何本机能力** |

**怎么建**：**Electron + Vite + React Router**，新建薄壳，**不 fork 任何现成产品仓**
（`D26`、`D27`）；窗口隔离与本机通道可定点移植开源实现，须保留来源、版本与许可声明。
与网页前端**界面不共享**，接口契约以后端 schema 为单一真源、两端各自生成客户端
（[`engineering.md`](../architecture/engineering.md)）。

**和谁交互**：经通道 ④ 与后端，经通道 ③ 本机管道与 runtime（**不开 TCP 端口**）。

**要满足什么**见子任务 [`submodules/0002-desktop/`](../submodules/0002-desktop/PRD/requirement.md)。
