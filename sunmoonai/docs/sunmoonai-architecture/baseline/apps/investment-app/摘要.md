## 1. 定位

投资研究与智能体域 App（曾用名 research-app）。拥有 Session/Thread/Run/Attempt/Invocation、
Graph/Runtime 与 Agent 产品状态；**不接管 Info/Knowledge 领域事实**。旧 Research 四组件无
运行态，历史材料只在冻结标签，不得复制回活动架构。

## 3. 关键入口

- Agent 领域模型（`domain/agent`）：Run 状态机（四终态不可转出）+ RunBudget 四维限额 +
  消息/事件 lineage + graph state 分层护栏（state/artifact 只存引用不存内容体）。
- LangGraph 图族：walking_skeleton（checkpoint 闭环验证）、pilot_graph（产品试点：强制真实
  draft + ≥1 真实 citation、interrupt 审批）、first_m1_graph（planner-react 雏形）；
  PostgresSaver checkpoint。
- Pilot 链（Web 用户面，真产品链）：幂等建 run → Knowledge 检索（**无授权证据即失败，不是
  空答案**）→ 只据证据回答的 LLM → interrupt/resume（token 原子消费，transport 失败即终态
  failed）；citation source 只回同源 BFF 路径。
- Agent v4 链（Admin 面）：流量门 `agent_v4_traffic_enabled` 关闭即全 404；session 锁 +
  SSE 先订阅后回放。
- 三类服务身份：入站 pilot（Web BFF 委托，X-Delegated-Actor-ID）、入站通用 subject 绑定、
  出站 knowledge retrieve。
