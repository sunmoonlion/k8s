# 账号、电脑、link、会合点

界面、文档、卡片说到这几样时，只用本页的叫法。

## 一、四样东西

| 东西 | 是什么 | 在哪 | 我们能知道它什么 |
| --- | --- | --- | --- |
| **账号** | 一个身份 | 云端 | 全部 |
| **电脑** | 一台实体机器 | 用户手里 | 只能听本地 link 报 |
| **本地 link** | 装在电脑上的程序（程序名 sunmoon-link） | 用户的电脑上 | 它报的电脑名（默认取操作系统主机名，可改）、设备编号、连没连着会合点 |
| **会合点** | 本地 link 往外连的中转服务器；工作台经它和本地 link 说话 | 云端 | 每个账号此刻有没有本地 link 连着 |

## 二、四种关系

| 关系 | 谁和谁 | 怎么建立 | 一对几 |
| --- | --- | --- | --- |
| **装在** | 本地 link 装在电脑上 | 安装 | 一台电脑装一份本地 link |
| **登录** | 浏览器用账号登录 | 在浏览器里登录 | 和另外三种关系无关：浏览器登的是 A，这台电脑的本地 link 可以配给 B |
| **配给** | 本地 link 配给某个账号 | **给 link 颁发令牌**：托盘「重新给 link 颁发令牌」→ 浏览器确认页 → 点「允许」，本地 link 拿到这个账号的令牌 | 一份本地 link 同时只配给一个账号；一个账号同时只配给一份本地 link（再颁发一次，旧令牌作废、旧的本地 link 断开） |
| **连着** | 本地 link 连着会合点 | 本地 link 拿令牌往外连，自动保持、断了自动重连 | 实时：电脑关、没登录系统、本地 link 没在运行、断网、令牌过期（30 天）就不连着 |

- **配给这个账号的本地 link** = 最后一次给它颁发这个账号令牌的那份本地 link。配给关系一直在，直到下次重新颁发令牌。
- 账号不连谁。不说「账号连着的 link」，说「配给这个账号的本地 link」和「它连没连着会合点」。
- **认本地 link 用设备编号**，不用电脑名；电脑名会重名，只给人看。设备编号用在两处：
  1. **打开工作台时的核对**（第四节）：比两个编号——**甲**：眼前这台电脑上的本地 link 的编号，网页在这台电脑的浏览器里直接问本机的本地 link 拿到；**乙**：配给当前登录账号的那份本地 link 的编号，它连会合点时报过、后端记着，网页问后端拿到。
  2. **「我的电脑」一份本地 link 一条记录**：同名的两台电脑不会并成一条；重新颁发令牌还是原来那条。
- **设备编号**：本地 link 第一次运行时随机生成一次，存进它在这台电脑上的配置目录，以后一直沿用（重新颁发令牌不变）。编号本身是随机数，不含电脑或 link 的信息；它代表「这台电脑上的这一份本地 link」，靠的是存放的位置。重装（配置目录删了）就是新编号；配置目录被整个拷到别的电脑会跟过去，所以本地 link 报编号时一并报主机名与系统，对不上就提示。不读硬件指纹。它和颁发令牌时那个一次性密钥是两回事——那个每次颁发都重新随机生成、用完不存。

## 三、界面上的词

| 词 | 意思 |
| --- | --- |
| 连着 / 没连着 | 配给这个账号的本地 link，此刻连着 / 没连着会合点。说的是本地 link，不是电脑：电脑开着、本地 link 没在运行，也是「没连着」 |
| 最近一次联系 | 最后一次看到它连着会合点的时间 |
| 工作台现在用的电脑 | 配给当前账号的那份本地 link 装在的电脑 |

不用「电脑在线、离线」「连到账号」「重新连接账号」「本地程序」「本地代理」。

## 四、打开工作台时的核对

核对一件事：**浏览器所在这台电脑上的本地 link，是不是配给当前登录账号的那份**，即比编号甲（眼前这台的）和编号乙（配给当前账号的），见第二节。结果在工作台顶上单独提示，只在要用户做事时出现；侧栏不挂这类状态。

| 结果 | 提示 |
| --- | --- |
| 甲 = 乙，而且连着会合点 | 不提示 |
| 甲 = 乙，但连不上会合点（本地 link 在运行，网断了、令牌过期或卡住） | 「本地 link 连不上：检查网络，或在托盘重启」 |
| 甲 ≠ 乙（这台的本地 link 配给了别的账号，或从没颁发过令牌） | 「工作台现在用的不是这台电脑」＋「重新给 link 颁发令牌」 |
| 甲拿不到（没装、没在运行、手机、浏览器不允许检测） | 一行小字「这台设备没有在运行的本地 link，或浏览器不允许检测；工作台现在用的是『电脑名』」，不强迫 |

连没连着、最近一次联系、电脑名与系统、接入日期，放「我的电脑」页。

## 五、常见情形

| 情形 | 配给 | 连着 |
| --- | --- | --- |
| 在电脑 P 上给账号 A 颁发令牌 | P 上的本地 link → A；A 之前配给的作废 | P 开着就连着 |
| 电脑 P 关机，或没登录系统 | 不变 | 不连着 |
| 在电脑 Q 上又给 A 颁发令牌 | Q 上的 → A；P 上的作废 | Q 连着，P 不再替 A 连 |
| 在电脑 P 上给账号 B 颁发令牌 | P 上的 → B，不再配给 A | 替 B 连着；A 在 P 上打开工作台时提示「工作台现在用的不是这台电脑」 |
| 用手机打开工作台 | 不变 | 不变；提示「这台设备没装本地 link」 |

## 六、本地 link 怎么保持运行

- **登录自启**：颁发令牌完成时，本地 link 自动打开「登录系统时自启」（Windows 任务计划程序里当前用户的登录任务，后台运行，失败每分钟重启、最多 3 次）；托盘可开关。开机后停在登录界面时不运行。
- **会合点断开不回应的**：会合点每 20 秒 ping 一次本地 link，不回就断开，「连着」以会合点看到的为准。本地 link 自己卡住时要在托盘重启。
