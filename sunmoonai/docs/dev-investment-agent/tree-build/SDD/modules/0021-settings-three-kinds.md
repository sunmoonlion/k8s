# 设置分三类：个人偏好 / 云端与模型 / 我的电脑（0021）

> 状态：所有者 2026-10-12 提出「设置不全，分三段：网页设置、后端设置（key、url、mcp）、runtime 设置」，远程建议按「设置住在哪、谁改得了」分，所有者同意：url 指模型接入地址；白名单从网页改和账 87 一起做。本篇取代 `0002-web-pages.md`「设置」一节与 `0012` §5 里关于设置页布局的描述；接 `0019`（长期记忆、本地知识库）、`0016`（侧边栏底部）、`0012`（接入电脑）。

## 一、分法

按真源分，不按代码层分：用户看到的是「这个设置管什么」，不是「它存在哪个进程里」。

| 类 | 叫法 | 真源 | 谁改得了 | 改了几时生效 |
| --- | --- | --- | --- | --- |
| 1 | **个人偏好** | 浏览器本地存储（第一期）；以后可同步到用户资料 | 本人 | 立刻 |
| 2 | **云端与模型** | 后端数据库，按账号 | 本人 | 云端沙箱重启或下一段对话 |
| 3 | **我的电脑** | 用户电脑上的代理（配置文件、白名单、自启任务） | 本人，经代理 | 代理重启或下次连接 |

## 二、每类里有什么

### 1. 个人偏好

来自旧 Vue 前端 `EPlus/Themes` 那套「主题设置」里**对工作台有意义的四样**；导航模式、标签页、面包屑、头部固定、切换动画、Logo 是后台模板的骨架，工作台没有这些元素，不搬。

| 项 | 值 | 说明 |
| --- | --- | --- |
| 语言 | 中文 / English | 现在跟地址走（`/zh-CN`、`/en`），这里给个开关，切了换地址前缀 |
| 外观 | 跟随系统 / 浅色 / 深色 | 默认跟随系统 |
| 主题色 | 几个预设 | 不开取色器，预设够用 |
| 侧边栏 | 宽度（三档）、默认展开哪一级（电脑 / 工作区 / 项目） | 现在的折叠记忆是一次性的，这里定默认 |

全部存浏览器本地（`localStorage`），不经后端；换浏览器要重设，第一期接受。

### 2. 云端与模型

现有的三块留在这里，加两样：

| 块 | 现在 | 加什么 |
| --- | --- | --- |
| 模型 key | 厂商 + key，服务端加密、不回显、可撤换 | **接入地址**（所有者说的 url）：自建或代理的 OpenAI 兼容端点，和 key 一行；空着就用厂商默认。后端 `AddCredential` 加 `base_url`（只许 `https://`，校验主机名，不许回环与内网段），凭据表加一列，沙箱配置渲染时带上 |
| 新对话的默认 | 模型、审批策略 | 不变 |
| 云端沙箱 | 拉起 / 更新 / 回收 | 不变 |
| **MCP 连接**（新） | — | Codex 在云端能用哪些数据源的开关清单：公共数据（knowledge，默认开）、选定专家的知识库（advisor，选了专家才出现，0018）、以后的外部 MCP（地址 + 令牌，服务端存，形状同 key）。第一期只做清单与开关，外部 MCP 另记账 |
| 长期记忆 | 已单独成页（0019） | 这里放一条入口 |

### 3. 我的电脑

现有的接入电脑一整节搬进来（0012 §5 的顺序不变），加代理侧的几样。**代理侧的设置要从网页改，走账 87 的通道**（代理经会合点接受来自云端、按用户签过的设置写入），和文件通道一起做；通道通之前这些项只显示、旁边写「在托盘「白名单与上限设置」里改」。

| 块 | 项 | 真源 | 通道通前 | 通道通后 |
| --- | --- | --- | --- | --- |
| 接入电脑 | 已接入的电脑、下载安装、连接一台电脑、已接入列表、高级 | 后端 + 代理 | 现状 | 现状 |
| 白名单与上限 | 目录清单、读写模式、网络、上限 | 代理 `config.json` | 只显示（代理 hello 已带 roots 与 ceiling） | 网页改 → 云端 → 会合点 → 代理写配置并重启自己 |
| 开机自启 | 开 / 关 | 代理的登录任务 | 只显示 | 可改 |
| 本地知识库目录 | 一个目录 | 代理 `config.json`（0019） | 只显示 | 可改 |
| 终端 | 允许 / 不允许从网页开本机终端 | 代理（0017 §五、账 83） | 不显示 | 终端做了再放 |

## 三、页面形状

- 设置页左边一列三项：**个人偏好 / 云端与模型 / 我的电脑**；右边一次只显示一类，每类内部还是一栏排下来、锚点可达。
- 侧边栏底部的「设置」默认进「云端与模型」；各处「接入电脑」链接直接落「我的电脑」（现有 `#computer` 锚点不变，`routes.computer` 指到第三类）。
- 地址：`/workbench/settings/{preferences|cloud|computer}`；旧地址 `/workbench/settings` 与 `#computer` 都转到对应类。

## 四、不做

- 导航模式、标签页、面包屑、全屏等后台模板的壳。
- 站点、Casdoor、会合点这类地址：是部署配置，归管理后台，不进用户设置。
- 多台电脑并存的切换（一账号一电脑，0012 账 91）。
