# 数据流与信任边界

> 由产品合同搬入。哪条数据走哪条通道，见 [通道](channels.md)。

**口径是「不经过我们」，不是「不出本机」。**只要模型在云上，Codex 读过的内容就离开了
这台机器——写成「不出本机」是假的。我们承诺的是：**资料与结果正文不经我们的后端、
不经知识服务**；发往哪家模型厂商由用户自选、自付，提交前界面告知。


| 数据 | 流向 |
| --- | --- |
| 用户 key | 只在用户电脑，只发给用户选择的模型厂商 |
| 用户提出的问题（任务文本、归一化目标、已确认的类别） | 明文发到后端，用于受理判定、路由与编排 |
| 用户自己的资料、文件名、Codex 取回的公开资料 | 存在用户电脑上的本地知识库，**不上传后端**；提交时只给句柄。⚠ 这一行说的是**存放与提交**；Codex 在执行中读过的内容按下一行处理 |
| 文件与研究内容 | **由 Codex 发给用户选择的模型厂商**；不上传后端。⚠ 这就是「不经过我们」的确切含义——内容确实离开这台机器，只是不经我们的后端；界面必须在提交前告知是哪一家 |
| 自有数据 | 按查询以片段形式下发到用户电脑 |
| 查询内容 | 发到知识服务；日志少记并告知用户 |
| 工具级审批细节（命令原文、改动、路径） | 只在本地窗口展示；后端只收摘要与结论 |
| 研究结果 | 本地检查后加密，后端只存密文与元数据，无法读取 |
| 任务元数据（状态、时间、用量、审计摘要、密文摘要值） | 后端 |

## 三把东西的逐跳归属

`key`（模型 key）、结果密钥、结果明文——**三把东西，三个归属，不要混说成「谁碰谁不碰」**。
两边都碰明文，区别在**解密能力只在一侧**。

⚠ **解密能力只给桌面应用，同时又要「加密在执行端完成」（`F-CRYPTO-01`），只有信封结构能同时成立：**
结果密钥是一对非对称密钥，**私钥只在桌面应用主进程**（存系统钥匙串），
**runtime 只拿到公钥**——它加密得了，解密不了。
这和 `F-CRYPTO-06`「以对方公钥加密结果密钥后分享」是同一个套路。
（若改成对称密钥存同一条钥匙串项，runtime 与桌面应用就都能解密，
「解密能力只在桌面应用」这条边界随即失效。）

| | 模型 key | 结果密钥 | 结果明文 |
| --- | --- | --- | --- |
| **在哪生成** | 用户在桌面应用本地窗口输入 | 密钥对在用户设备上生成（`F-CRYPTO-01`） | Codex 产出 |
| **持久保存在哪** | runtime 侧系统钥匙串 | **私钥**在桌面应用主进程侧系统钥匙串；**公钥**可给 runtime | **不持久保存明文**；落盘的只有密文 |
| **哪个进程碰得到** | runtime 进程；启动 Codex 时经环境变量传（⚠ 子进程继承边界未核实，见 [`models-and-keys.md`](../submodules/0003-runtime/PRD/models-and-keys.md)） | 私钥：桌面应用**主进程**，渲染进程**不持有**；公钥：runtime | 加密前：runtime；解密后：桌面应用**渲染进程**（经 IPC 收明文片段） |
| **谁能解密** | — | **只有桌面应用主进程**（它独持私钥）；runtime 只有公钥，加密得了解密不了 | — |
| **后端** | 协议无此字段（`I16`） | 私钥不进任何协议字段；后端**不具备解密能力**（`F-CRYPTO-02`） | 只见密文与元数据 |
| **经桌面应用转发吗** | 输入后经 ③ 交给 runtime，桌面应用**不留存** | 公钥经 ③ 给 runtime；私钥不转发 | 密文经后端流到桌面应用，**不经 runtime 回传明文** |

**逐跳**：

```text
Codex 产出正文
  → runtime 做本地内容检查 → runtime 用结果公钥加密（F-CRYPTO-01；它没有私钥，加密得了解密不了）
  → 密文 + 检查回执经 ① 上报后端（后端只存密文与元数据，F-CRYPTO-02）
  → 桌面应用经 ② 取密文
  → 桌面应用主进程从钥匙串取结果私钥、解密（F-CRYPTO-03）
  → 经 IPC 把明文片段给渲染进程渲染
```

换设备时由用户凭恢复码或设备间迁移取得**私钥**（`F-CRYPTO-04`）；丢了没有后门（`F-CRYPTO-05`）。

⚠ **明文不得出现在**：任何协议字段、事件、日志、崩溃报告、`localStorage`、`IndexedDB`、
临时文件（`I12`、`I17`）。渲染进程 `nodeIntegration` 关、`contextIsolation` 开。
