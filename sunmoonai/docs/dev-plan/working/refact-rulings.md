## R1 — 免除 kimi 的 ④ 异议

| 项 | 内容 |
| --- | --- |
| **事由** | 发起人裁定：kimi 响应速度不足以支撑本轮 ④→⑤ 的推进 |
| **依据** | **不按逾期判据**，是发起人的直接裁量。支持性观测（2026-09-04 16:21）：① 提案 kimi 交付最晚（09-04 12:5x，其余三家 09-03 20:09 / 09-04 10:00 / 11:22）；② 互评 kimi 评审 16,768 B，四家最小；④ 通知发出后 luna、cursor 已交异议，kimi 与 qwen 未开始 |
| **处置** | kimi 不参加 ④ 异议；其未提异议**不计为弃权，也不计为认可**，计为「经裁定免除」 |
| **方向** | **更省事**（免除一家 = 少一次检查） |
| **人确认** | **是**——发起人直接指示 |
| **影响到谁** | kimi（被免除）；裁决方（少一路检查） |
| **覆盖了哪条规则** | 「④ 异议：触发——只发给被处置到的家」。kimi 是被处置到的家，本应参加 |

**必须记下的代价**：kimi 是本轮**唯一被改判了判断**的家（`F-EXEC-02` dsh 腿，
由「已支持（设计）」改判「当前缺失（turn 级）」），另有一条 D 块建议未被采纳。
免除它的 ④，等于**移除了对裁决方这条最实质推翻的唯一直接检查**。

该风险的剩余缓解：⑤ 验收会独立复核「处置记录与实际 diff 是否对得上」；
⑥ 人确认仍在。且 kimi 依「裁量权 · 推翻」仍可随时就本裁定或该改判提异议——
**本裁定不剥夺它的申辩权，只是不再等它**。
