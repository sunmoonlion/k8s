# ADR-0002：每类业务数据只有一个权威主档

- 状态：已接受
- 日期：2026-06-11

## 背景

业务数据可能同时出现在 PostgreSQL、MinIO、Elasticsearch、RAGFlow、缓存和下游应用中。如果没有唯一权威来源，删除、修订、恢复和审计将无法保持一致。

## 决策

每类业务数据指定唯一 System of Record。其他存储只能保存引用、快照、索引、缓存或可重建副本。

权威数据必须具有稳定标识、必要版本、审计信息和备份策略。派生系统必须提供失效、对账和重建能力。

## 结果

- `info-app` 拥有资讯和原始证据。
- `auth-app` 拥有身份和权限。
- `llm-app` 拥有模型及知识处理配置，不拥有其他领域主数据。
- `investment-app` 拥有投资领域数据。
- 搜索、向量、缓存和 RAG 数据不能成为唯一主档。
