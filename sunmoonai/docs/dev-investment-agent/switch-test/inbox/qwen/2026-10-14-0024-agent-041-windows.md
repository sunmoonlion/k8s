# Qwen 卡：代理 0.4.1「新建项目」Windows 真机验证（0024 段 2）

```text
在哪：所有者机器（Windows + WSL），runtime 仓 qwen 工作树；Windows 侧用官方 node.exe 24.19.0、Codex 0.155.1
代码：runtime f09ec89（代理 0.4.1：回环口建文件夹、拉取 git 仓库）
预计：30–60 分钟
不碰：现装代理、登录任务、托盘、所有者账号与项目；不 push、不发布、不改别的仓
回传：runtime/scripts/results/windows-agent-0.4.1-projects.<时间>.md，最后一行 exit=<码>；本地提交
```

## 为什么

10-14 现网：新建项目只在工作台登记路径，电脑上没有那个文件夹，工作对话写 `hello.txt` 时代理反复报「Windows 工作目录不存在」，模型转去请求提权。0.4.1 让代理在新建时就把文件夹建好（走 Windows 文件助手已审的 `fs/createDirectory`），或把 git 仓库拉好。远程在 Linux 上测过（323 过），**Windows 没验过**，这张卡验它。设计 `k8s/.../SDD/modules/0024-new-project.md`。

## 一、核对

1. 所有者已跑 `WS=qwen` 同步。`git -C <runtime qwen 工作树> rev-parse HEAD` = `f09ec89…`（前缀对上即可），`git status --porcelain` 干净。
2. Windows 上有 git（`git --version`），能连 github.com（公开仓库要用）。连不上就换一个国内能拉的公开仓库地址（例如 gitee 上的公开仓库），在回执里写明换了哪个。

## 二、准备隔离源码（同 0.4.0 段 1 的做法）

1. 在 runtime/agent 下 `pnpm install --frozen-lockfile`、`pnpm build`。
2. 建隔离目录 `C:\Users\zymun\sunmoon-probe-runs\windows-agent-041\app\`，放进：`dist\`、`native\`、`package.json`，以及与 0.4.0 发布同一份已核验的 Windows 运行依赖（`node_modules`，含 `smol-toml`、`ws`、`@openai/codex`、`@openai/codex-win32-x64`）。
3. 核对 `dist\localProjects.js` 在、`package.json` 的 version 是 `0.4.1`。

## 三、跑探针

在 Windows 的 PowerShell 里，用官方 node.exe：

```powershell
& <官方 node.exe> <runtime>\agent\test\local-project-windows-probe.mjs C:\Users\zymun\sunmoon-probe-runs\windows-agent-041\app
```

要看到最后一行 JSON，下面各项都是 `true`：`chinese_nested_folder`、`case_kept`、`existing_folder_not_created`、`root_as_project`、`outside_and_library_denied`、`file_in_the_way_409`、`junction_denied`、`read_only_denied`、`public_clone`、`non_empty_denied`、`file_transport_denied`、`timeout_removes_folder`；`public_branch` 有值。探针用的全是自己建的临时目录，退出时自己清掉。

**私有仓库（可选，所有者愿意才做）**：所有者在**自己的** PowerShell 里设 `$env:SUNMOON_PROBE_TOKEN = '<令牌>'`，再带第二个参数跑：

```powershell
& <官方 node.exe> <runtime>\agent\test\local-project-windows-probe.mjs <隔离 app> <公开仓库> <私有仓库 https 地址>
```

要看到 `private_without_token` = `auth_required`（电脑上没有这个仓库的登录时），`private_with_token` = `true`。令牌不进回执、不进日志、不进命令历史截图；做完 `Remove-Item Env:SUNMOON_PROBE_TOKEN`。所有者不做，就在回执写「私有仓库未验」。

## 四、Windows 上的已有单测

用 Windows 的 node 跑一遍代理全量单测（同 0.4.0 那次的做法），记通过 / 跳过数；`localProjects.test.ts` 里依赖 Linux 的用例在 Windows 上失败要逐条列出来，不要改测试。

## 停下的规则

任何一步失败就停在那一步，把输出（去掉路径里的用户名以外的敏感信息、去掉令牌）贴进回执，不改代码、不重试成功了再报。

## 回执写什么

- runtime HEAD、隔离目录里的版本与文件数；
- 探针 JSON 原样（不含令牌）；
- 私有仓库做没做；
- Windows 单测数字；
- 结论：哪些过、哪些没过、哪些没验。
