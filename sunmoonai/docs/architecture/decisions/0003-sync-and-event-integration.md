# ADR-0003：同步 API 与异步事件并用

- 状态：已接受
- 日期：2026-06-11

## 背景

用户交互需要同步响应，采集、文件处理、知识同步和跨应用通知则可能耗时较长。只使用同步调用会形成长依赖链，只使用消息又会增加简单查询的复杂度。

## 决策

- 即时查询和短命令使用版本化同步 API。
- 已发生的领域事实使用领域事件发布。
- 长耗时执行请求使用任务消息。
- 事件通过 Transactional Outbox 可靠发布。
- 消费者实现幂等、死信、重放和周期性对账。

## 结果

- RabbitMQ 是传输基础设施，不是业务主档。
- 部署优先级不代表运行时依赖可靠。
- 每个跨 App 集成都必须定义超时、重试、幂等和失败恢复。
