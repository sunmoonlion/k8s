# 附录：PRD 模板（任务书）

```markdown
# <任务编号>：<短名>

- 父任务：<父任务目录；根任务写「无」>
- 由什么产生：<父任务 SDD 的哪一版（提交号）、哪一节；根任务写「人提出」>
- 谁写的：<人；子任务写「来自父任务 SDD 第 n 版，经人批准」>
- 交付物清单：<SDD / SDP / UAT 中的哪几项>；每项的形态：<只交文本 / 会改文件，可改的范围是……>
- 需要人批准的动作：<列出；没有写「无」>
- 返工上限：2

## 要什么
<做完之后什么变了；为什么要做>

## 范围
- 包含：
- 不包含：
- 不包含的归谁：

## 验收标准
1. <可判定的条件，做完能一条条对着勾>

## 约束
<必须遵守的规则、不能动的东西>
```
