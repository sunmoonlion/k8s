# celeryworker-llm-admin-backend 创建说明

## 定位

该组件对应 `tpl-app/celeryworker-tpl-admin-backend` 模板实例化后的结果，服务 `llm-admin-backend` 的异步任务。

## 配置关系

- Worker 默认镜像：`harbor.sunmoonai.com:30443/k8s-images/llm-admin-backend:1.0.0`
- 业务配置来源：`llm-admin-backend-config`、`llm-admin-backend-secret`
- Worker 自身配置：`celeryworker-llm-admin-backend-config`、`celeryworker-llm-admin-backend-secret`
- 队列：`llm.admin.default`

数据库、Neo4j、Redis 等业务连接不在 Worker 中重新维护，继续复用 `llm-admin-backend` 的 ConfigMap/Secret。

## RabbitMQ

`declare-rabbitmq-queue` initContainer 会用 `CELERY_BROKER_URL` 声明 `CELERY_QUEUE`。RabbitMQ 用户、密码、vhost 和权限需要由 RabbitMQ 组件或运维侧提前提供。
