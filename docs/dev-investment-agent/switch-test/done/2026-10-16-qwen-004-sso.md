## 会发生什么（先知道）

- **Casdoor 会重启一次**（配置变了，Pod 注解是配置摘要）：重启时所有人的登录都会掉，要重新登录。
- 六个应用各跑一次新的身份注册 Job（`*-identity-…-v4`）：网页端在 Casdoor 里打开「保持登录会话」「自动登录」，两端回调旁多登记一个 `/api/auth/<web|admin>/logged-out`。脚本只认「改版前的样子」才迁移，别的不一致照旧停。
- 六个应用重建镜像、滚动更新。
- **退出的行为**：在某个应用退出，会结束 Casdoor 会话（再进别的应用要输密码）；已经打开并登录着的其他应用，本地会话仍有效，直到它自己过期（最长 1 小时）或在那里退出。全局一处退出处处退出不在本卡。
- 公网边缘的放行清单要加 `/api/logout`，那一步 Opus 在远程机做，另请所有者批准，不在本卡。

必须用 bash。每一步出 `exit` 不为 0、`STOP`、或与「要看到」不符就停，把输出原样交上来，不修、不重跑。命令里不贴口令与令牌。

**E0 拉代码**（k8s 与六个应用的父仓、子仓都到远端 `qwen`；构建链读的是 k8s 旁边这些检出，HEAD 要等于 `sources.yaml` 钉的提交、工作区干净）：

```bash
cd ~/worktrees/qwen/k8s && git pull --ff-only origin qwen && git log --oneline -1
for a in tpl knowfeed knowbase investment knowlab knowmart; do
  W=~/worktrees/qwen/$a-app
  git -C "$W" fetch -q origin qwen && git -C "$W" merge -q --ff-only FETCH_HEAD || { echo "STOP $a parent"; break; }
  for s in backend web-frontend admin-frontend; do
    git -C "$W/$a-$s" fetch -q origin qwen && git -C "$W/$a-$s" merge -q --ff-only FETCH_HEAD || { echo "STOP $a-$s"; break 2; }
  done
done
python3 - <<'EOF'
import subprocess, yaml, os
W = os.path.expanduser('~/worktrees/qwen')
lock = yaml.safe_load(open(f'{W}/k8s/infrastructure/applications/sources.yaml'))['applications']
head = lambda p: subprocess.run(['git', '-C', p, 'rev-parse', 'HEAD'], capture_output=True, text=True).stdout.strip()
dirty = lambda p: subprocess.run(['git', '-C', p, 'status', '--porcelain'], capture_output=True, text=True).stdout.strip()
bad = 0
for a, v in lock.items():
    for path, want in [(f'{a}-app', v['parent_revision']), (f'{a}-app/{a}-backend', v['backend_revision']),
                       (f'{a}-app/{a}-web-frontend', v['web_revision']), (f'{a}-app/{a}-admin-frontend', v['admin_revision'])]:
        p = f'{W}/{path}'
        if head(p) != want or dirty(p):
            print('STOP', path, head(p)[:8], 'want', want[:8], 'dirty' if dirty(p) else ''); bad = 1
print('pins-ok' if not bad else 'pins-bad')
EOF
```

要看到：最后一行 `pins-ok`，前面没有 `STOP`。
