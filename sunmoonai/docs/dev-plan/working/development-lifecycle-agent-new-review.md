## 2. 验收标准（权重在评分前冻结）

硬门禁（任一不过即不进入偏好比较）：

- **G1 写全**：执行所需纪律自足，不寄托于会被删除的文档或不存在的文件（链接可解析）；

- **G3 产出物/commit 场景处置**：覆盖 2026-09-02 事故教训，场景枚举充分、分别处置、含
  事后处置；

  制造悬空引用。

质量偏好与权重：模型忠实 30 / 场景处置 25 / 写全与体系兼容 20 / 可执行性 15 / 可维护性 10。
