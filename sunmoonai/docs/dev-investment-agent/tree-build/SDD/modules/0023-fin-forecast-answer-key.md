## 怎么跑

每题开一段新的专家对话（同一个项目即可），原样贴问题。跑完一题，把项目里的 `底稿/财务分析与预测-成稿.md` 与 `交回.md` 改名加题号（如 `01-成稿.md`、`01-交回.md`）再跑下一题——不改名的话下一题会覆盖。哪一题停下来要你答，把页面上的问题与你的答复记下来。
