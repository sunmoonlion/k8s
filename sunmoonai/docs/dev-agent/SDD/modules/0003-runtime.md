# 0003-runtime：本地 runtime

**承担**：跑在用户电脑上的常驻后台进程。主动连后端；接收 Attempt 并经 Codex Python SDK
驱动 Codex；向 Codex 提供本地 MCP 与公开资料取数工具，并把后端的方法工具**代理**成本地 MCP 工具；做工具级审批与副作用记账的拦截点；
保管 key；定工作区与沙箱策略；对结果做本地内容检查与加密；上报事件、用量、副作用意图与回执。

**不承担**：

- **不持有任何持久化账的权威副本**，也不自行决定 Task 状态；
- 不做界面——一切用户交互经通道 ③ 交给桌面应用；
- **不实现、不缓存方法工具**：只把调用经 ① 转给后端执行。缓存或本地实现等于把方法落地到用户电脑，
  而方法库的前提是「收在后端，不落地到用户电脑」。

**跑在**用户电脑上，注册为用户级后台服务，**关掉桌面应用窗口仍在跑**。
**信任域**：三方里**唯一同时碰得到 key 和结果正文**的一方——桌面应用不碰，后端看不到。
这是它与 `0002-desktop` 必须分开的唯一理由。

**和谁交互**：经通道 ① 与后端，经通道 ② 驱动 Codex，经通道 ③ 与桌面应用；
Codex 再经 ⑤ 调知识服务、经 ⑥ 调模型厂商。

**要满足什么**见子任务 [`submodules/0003-runtime/`](../submodules/0003-runtime/PRD/requirement.md)。
