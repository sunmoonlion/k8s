# ONLYOFFICE Docs 数据库用户创建指南

本文档说明如何为 ONLYOFFICE Docs 创建所需的数据库用户和设置密码。

## 1. PostgreSQL 用户创建

### 连接信息
- **主机**: 101.126.151.0（集群1节点IP）
- **端口**: 30444（Traefik TCP 路由）
- **用户名**: onlyoffice_docs
- **数据库名**: onlyoffice_docs

### 创建步骤

#### 方式1：通过外部端口连接（推荐）

```bash
# 连接到 PostgreSQL（需要管理员密码）
psql -h 101.126.151.0 -p 30444 -U postgres -d postgres

# 或者使用环境变量
export PGPASSWORD="PostgreSQL@12345"  # 替换为实际的管理员密码
psql -h 101.126.151.0 -p 30444 -U postgres -d postgres
```

#### 方式2：通过 Kubernetes Pod 连接

```bash
# 切换到集群1
export KUBECONFIG=/home/zym/.kube/cluster-c1-admin.conf

# 查找 PostgreSQL Pod
kubectl get pods -n data-platform-dev | grep postgresql

# 进入 Pod 执行命令
kubectl exec -it <postgresql-pod-name> -n data-platform-dev -- psql -U postgres
```

### 创建用户和数据库

```sql
-- 1. 创建用户（请替换 'your_secure_password' 为实际密码）
CREATE USER onlyoffice_docs WITH PASSWORD 'your_secure_password';

-- 2. 创建数据库
CREATE DATABASE onlyoffice_docs OWNER onlyoffice_docs;

-- 3. 授予权限（如果需要）
GRANT ALL PRIVILEGES ON DATABASE onlyoffice_docs TO onlyoffice_docs;

-- 4. 验证创建
\du  -- 查看用户列表
\l   -- 查看数据库列表
```

### 配置密码

在配置文件中设置密码：
```bash
# 编辑配置文件
vim /home/zym/k8s/sunmoonai/app-platform/shared-apps/onlyoffice-docs-app/onlyoffice-docs-bff/secrets/onlyoffice-postgresql-secret/deploy-onlyoffice-postgresql-secret/deploy-onlyoffice-postgresql-secret.conf

# 设置密码
POSTGRESQL_PASSWORD="your_secure_password"
```

## 2. Redis 密码配置

```bash

# 在 redis.conf 中添加：requirepass your_redis_password
```

### 配置密码

在配置文件中设置密码：

## 快速创建脚本

### PostgreSQL

```bash
#!/bin/bash
# 创建 PostgreSQL 用户和数据库

PGHOST="101.126.151.0"
PGPORT="30444"
PGUSER="postgres"
PGPASSWORD="PostgreSQL@12345"  # 替换为实际管理员密码
DB_USER="onlyoffice_docs"
DB_NAME="onlyoffice_docs"
DB_PASSWORD="OnlyOffice@2024!"  # 替换为实际密码

export PGPASSWORD="$PGPASSWORD"

psql -h "$PGHOST" -p "$PGPORT" -U "$PGUSER" -d postgres <<EOF
CREATE USER $DB_USER WITH PASSWORD '$DB_PASSWORD';
CREATE DATABASE $DB_NAME OWNER $DB_USER;
GRANT ALL PRIVILEGES ON DATABASE $DB_NAME TO $DB_USER;
EOF

echo "PostgreSQL 用户和数据库创建完成"
echo "用户名: $DB_USER"
echo "数据库: $DB_NAME"
echo "密码: $DB_PASSWORD"
```

### Redis

```bash
#!/bin/bash
# 设置 Redis 密码

REDIS_HOST="101.126.151.0"
REDIS_PORT="30446"
REDIS_PASSWORD="Redis@2024!"  # 替换为实际密码

redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" CONFIG SET requirepass "$REDIS_PASSWORD"

echo "Redis 密码设置完成"
echo "密码: $REDIS_PASSWORD"
```

### RabbitMQ

```bash
#!/bin/bash
# 创建 RabbitMQ 用户

export KUBECONFIG=/home/zym/.kube/cluster-c2-admin.conf
NAMESPACE="messaging-platform-dev"
RABBITMQ_POD=$(kubectl get pods -n "$NAMESPACE" | grep rabbitmq | head -1 | awk '{print $1}')
RABBITMQ_USER="onlyoffice_docs"
RABBITMQ_PASSWORD="RabbitMQ@2024!"  # 替换为实际密码

kubectl exec -it "$RABBITMQ_POD" -n "$NAMESPACE" -- rabbitmqctl add_user "$RABBITMQ_USER" "$RABBITMQ_PASSWORD"
kubectl exec -it "$RABBITMQ_POD" -n "$NAMESPACE" -- rabbitmqctl set_permissions -p / "$RABBITMQ_USER" ".*" ".*" ".*"

echo "RabbitMQ 用户创建完成"
echo "用户名: $RABBITMQ_USER"
echo "密码: $RABBITMQ_PASSWORD"
```

## 注意事项

1. **密码一致性**：确保在创建用户时设置的密码与 Secret 配置文件中的密码完全一致
2. **安全性**：使用强密码，建议包含大小写字母、数字和特殊字符
3. **权限**：确保用户有足够的权限访问所需的数据库和资源
4. **网络**：确保 ONLYOFFICE Docs 能够访问这些服务（跨集群访问需要网络连通）
