## 异议 4｜DoD「已记录或已获授权」析取

| 项 | 内容 |
| --- | --- |
| **条目** | qwen｜DoD「已记录或已获授权」析取（`disposition.md:88`，拒绝） |
| **为什么错** | cursor 将「已记录或已获授权」理解为「未授权动作只因留记录而算完成」，这是对析取语义的过度解读。原意是：对于不可逆副作用，**授权记录**与**执行/审计记录**二者至少存在其一即可满足 DoD 的追溯要求，而非用记录替代授权。处置记录未区分「记录作为授权凭证」与「记录作为事后审计」两种情形。 |
| **应当是什么** | 接受 D6 为「不可逆副作用已记录或已获授权」的析取形式，但附加说明：若动作本身需要预先授权，则授权记录是必要项；若动作属于已批准的常规操作，执行记录即可满足审计要求。 |
| **证据** | qwen ① 候选 `pipeline.md:83` 原文为「不可逆副作用已记录或已获授权」；项目既有 `constraints.md:90`（I5）与 `agent-dev-guide.md:861` 均强调授权必须有显式记录，说明「授权」与「记录」在本项目中并非互斥，而是可以合并为同一追溯对象。 |
