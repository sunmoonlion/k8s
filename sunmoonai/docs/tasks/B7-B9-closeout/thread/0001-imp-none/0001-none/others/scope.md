## 不可变边界与验证

- D1/D2/D8：只对随机新建测试数据库迁移、备份和恢复，不连接业务库；不改迁移链。
- I3/I8：验证真实独立身份、拒绝及旧连接行为，不用管理员执行代替受限角色验收。
- R6/T4/T5：共同测试放模板；各实例用自己的迁移与策略；最终按仓与提交交付。
- 测试使用现有本地固定 Docker 镜像、最多一套 PG/broker，无外部收费服务；不下载模型。
- 退出条件：权限边界、产品选择或业务切换对象需要新增决定时保留证据并请求用户；
  不为把 B7 打勾而扩大现有授权。测试失败先查因，不删除断言或吞掉错误。
- 回滚：撤销本次测试/文档提交；测试夹具仅清理自己完整 ID 对应的容器及合成数据。
- 当前 `kubectl` 默认 context 未设置；本轮隔离测试不依赖默认集群，也不擅自切 context。
