## `A-2` 的自验（被指控的是本家，独立复核后认账）

我的候选第 342 行原文：「可跨会话续接 ｜ **人的 Attempt** 无 checkpoint 义务」。

- B4（任务书）：「**人不是执行者**。人的位置是 requester 与 principal」；
- Attempt 是执行者跑的对象，「人的 Attempt」这五个字本身就把人放进了执行者槽位——
  即使后半句是想免除义务，也先建了不该存在的槽位；
- 对照 `A-3` 对 `cursor` 的推翻理由恰好印证这条边界：`cursor` 那句「Side Effect 由人执行
  本地合并」描述的是物理动作、未把人建模进状态机，所以不违反；我那句是**建模措辞**，
  不是动作描述。两处裁定用的同一把尺，我认。

**可复跑证据**：`git show runtime-refact/kimi:sunmoonai/docs/dev-plan/agent-dev-guide.md | sed -n 342p`。
