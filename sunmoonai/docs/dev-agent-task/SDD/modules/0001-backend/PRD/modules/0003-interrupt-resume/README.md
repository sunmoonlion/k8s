# 0003-interrupt-resume：要满足什么

> 依据：[后端需求层](../../architecture/README.md) 与 [产品合同](../../../../../../../product/product-contract.md)。

## 职责

中断、批准与恢复。具体要求以合同里对应的功能 ID 为准，本文不复制第二份定义。

## 对应的合同条款

见 [产品合同](../../../../../../../product/product-contract.md) 的 `F-*` 与 `I*`：本模块负责其中属于「中断、批准与恢复」这一段的功能 ID 与不变量，以及 `AT-*` 里对应的验收场景。

## 验收

- 所负责的功能 ID 全部可验证；
- 相关不变量由存储与并发控制保证，不靠自律；
- 合同 `AT-*` 中对应场景可复现。

## 约束

[代码规则](../../../../../constraints.md)、[IMP 规则](../../../../../../../dev-agent-standards/imp/imp-rules.md)，以及合同的不变量。
