# 0002-desktop：桌面应用

**承担**：用户唯一的工作界面。提交 Task、看进度与结果、任务历史、研究底稿查看与编辑、
本地知识库管理、Task 级审查、工具级审批与本地确认、key 与模型配置、工作区授权、设备与计费；
拉起 runtime 并确保它在跑；托盘、通知、开机启动。

**不承担**：

- 不持有领域事实；
- **不自己调用模型**；
- **审查窗口不挂本机能力**——它展示的内容来自后端，外来内容加本机能力就是提权路径；
- 不负责 runtime 的存活与崩溃重启，那归系统的服务管理器。

**跑在**用户电脑上。**信任域**：碰不到 key，也碰不到结果正文以外的执行能力；
三扇窗口各自一个 webContents，**能力按窗口授予**。

**和谁交互**：经通道 ④ 与后端，经通道 ③ 本机管道与 runtime（不开 TCP 端口）。

**要满足什么**见子任务 [`submodules/0002-desktop/`](../submodules/0002-desktop/PRD/requirement.md)。
