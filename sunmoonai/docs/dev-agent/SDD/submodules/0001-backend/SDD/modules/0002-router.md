# 0002-router：受理与路由

**承担**：合同 `control-plane.md` 里 **router 角色**的全部职责。

- 身份从认证上下文确定（**不信任客户端自报**）、幂等键校验、建单、契约固定；
- **任务类别的三层判定**：用户所选 → 本机预填经用户确认 → 后端确定性规则兜底；判不出来交用户选；
- 路由决定：选 Task Profile、Agent Profile、执行设备；
- 路由规则是**版本化配置**，变更落事件；依据、规则集版本、所选模型与拒绝原因入账。

**不承担**：

- **不调用生成式模型**（v1 确定性规则，D11 未定之前不变）；
- 不推进 Attempt——契约固定后交给 `0003-orchestrator`；
- 不自己写状态与账，经 `0001-state`。

**边界要点**：身份与幂等必须在**同一个事务边界**内完成；一旦分配 `task_id` 并写首个事件，
后续业务或政策拒绝也必须形成**可审计的 `REJECTED` Task**，不能静默丢弃。
