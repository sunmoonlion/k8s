# thread 与 turn 的编号

> 依据的通用规范：[任务的生命周期「turn：一问一答」](../dev-agent-standards/lifecycle.md)

本任务树下的每个任务目录，`thread/` 的编号都按这里写的来。

## 要分开表达的三件事

编号要同时表达三件事，它们互不相干，所以各用各的写法：

| 事情 | 用什么表达 |
| --- | --- |
| **先后**：这是第几次派工 | turn 号 `01`、`02`… |
| **并行**：同一问同时发给几家 | turn 目录下的尝试 `a`、`b`、`c`… |
| **会话**：哪些 turn 共用一个上下文 | 任务书里的 `thread` 字段 |

三件事挤进一个编号，就会出现「一问变成几份任务书」和「看不出返工是接着问还是重问」两种含糊。

## 目录形状

一次普通派工，turn 目录直接放任务书、回执与交回物；同一问并行发给几家时，任务书仍只有一份，
放在 turn 目录下，各家各占一个尝试子目录。目录名是**本地号加上执行环境的 id**：

```text
<任务目录>/thread/
├── 01-01k8f3m2qz/       一次普通派工：user-message.md、turn.md 与交回物
├── 02-01k8g7p0aa/
└── 03/                  同一问并行发给两家
    ├── user-message.md  这一问只有一份
    ├── a-01k8h2r5bb/    turn.md 与交回物
    └── b-01k8h9t1cc/
```

- **并行的 turn 目录只有本地号**：几家各跑各的，没有一个属于整次的 id；id 落在各尝试目录上。
- 单 turn 目录下不得有尝试子目录；并行 turn 目录下不得直接放 `turn.md` 或交回物。
- **回执一家一份**：并行时每个尝试目录各有自己的 `turn.md`，turn 目录本身没有。某个尝试没有 `turn.md`，就是这家还没交回；几家都没有，才是整次还没交回。
- 行文引用只用本地号：`turn 03` 指整次派工，`turn 03b` 指其中第 b 次尝试，不带 id 后缀。定稿设计写明以哪一个为底。
- 验收 turn 的 `verifies` 填被验的本地号，如 `03` 或 `03b`。

## 名字怎么起

**`<本地号>-<执行环境的 id>`。**前半截管排序和引用，后半截管回溯原始记录，两件事在同一个名字里各归各位。

- 本地号两位数字，按**派出顺序**递增，从 `01` 起；只表示先后，不表示时间。
- **不跳号、不复用**：中断、失败、被替换的 turn 照样占住自己的号，目录与回执都留着。
- 并行尝试用小写字母，从 `a` 起连续；尝试数在派出时定，之后不再追加。
- 返工、改判、验收都是新的 turn，按同一个序列往下编，不另起一套编号。
- id 后缀**写全，不截断**——截断了就对不上执行环境的记录，这个后缀也就白带了。
- 派出时可以先只用本地号建目录；**写 `turn.md` 时必须已经带上后缀**。执行环境不给 id 的（比如人自己做的那次）写 `-none`。
- 改名只发生在交回之前。带了 `turn.md` 的目录连同名字一起冻结，此后不改。

## 会话写在字段里

`user-message.md` 的 YAML 头加一项 `thread`，写法与目录名一样——本地会话号加上执行环境的 thread id：

```yaml
thread: 01-01k8f3m2qz
```

| 怎么派的 | 编号怎么走 |
| --- | --- |
| 接着原来的上下文追问或返工 | 新 turn，`thread` 不变 |
| 换一个干净的上下文重问 | 新 turn，本地会话号加一，后缀换成新会话的 id |
| 同一问并行发给几家 | 新 turn；这一份任务书不写 `thread`，各家的会话写在各自 `turn.md` 的 `thread` 里 |

同一个本地会话号的后缀必须相同，不同会话号的后缀必须不同；没有 id 的写 `01-none`。

id 既然在名字里，**`turn.md` 不再重复写 `provider_turn_id`、`provider_thread_id`**——同一件事只留一处，
免得两处对不上时不知道信哪个。执行环境的原始记录在哪，仍写 `provider_record`。

## 门禁查这几条

编号规则要能被机器判，[`../tools/doc-gate.py`](../tools/doc-gate.py) 查：

| 查什么 | 判据 |
| --- | --- |
| 名字格式 | `<两位数字>` 或 `<两位数字>-<id>`；尝试目录 `<字母>-<id>`；有 `turn.md` 的必须带后缀 |
| 目录形状 | 单 turn 与并行 turn 两种形态之一，不得混；并行 turn 目录不带 id |
| 编号连续 | 本地号从 `01` 起不跳号、不复用；尝试字母从 `a` 起连续 |
| 会话一致 | 同一本地会话号的 id 后缀相同，不同号的不同 |
| 验收指向 | `verifies` 指到存在的 turn 或尝试 |
