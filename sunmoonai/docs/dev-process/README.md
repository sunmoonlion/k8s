# 开发流程规范

开发周期各阶段的通用规范：每个阶段写什么、按什么模板、过什么门。
它与任务的生命周期正交——任何开发任务（如 [`../dev-agent-task/`](../dev-agent-task/)）在任何层次、用到哪个阶段，就按该阶段的规范写；用哪几个阶段、各写多深，由任务的种类和需要决定。

- [`01-prd/`](01-prd/)：PRD（需求与验收合同）
- [`02-tld/`](02-tld/)：TLD（总体设计）
- [`03-sdd/`](03-sdd/)：SDD（详细设计）
- [`04-sdp/`](04-sdp/)：SDP（实施计划）
- [`05-acceptance/`](05-acceptance/)：验收（验证与验收）
