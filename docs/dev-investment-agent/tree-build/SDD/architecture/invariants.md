# 全程不变量与持久化账

> 旧树 `I1`–`I20` 中 `I14`（租约）、`I16` `I17` `I20`（加密与不上传）、`I18`（审批只来自本地）、`I19`（离线记账）退役；其余重编为 `I1`–`I14`。

## 全程不变量

| ID | 必须成立 | 防止的失败 |
| --- | --- | --- |
| I1 | 原始输入、调用者、受理时间与 Profile、专家包版本可追溯，不被后续解释覆盖 | 意图漂白 |
| I2 | 相同幂等作用域、键与摘要只对应一个 Task；异摘要冲突 | 重复建单或误复用 |
| I3 | 每次读取、工具调用与写入重新校验当前授权 | 撤权后继续访问、越权泄漏 |
| I4 | 状态转换集中校验，事件只追加；状态与进度是事件投影 | 状态多头、覆写历史 |
| I5 | Task 与 Attempt 终态不可转出；重新处理建立新实体；Codex thread 不是真源 | 终态失真、两个真源 |
| I6 | Task 成功前结果与验收证据已持久化且可重新获取 | 完成即丢失 |
| I7 | 通知与连接失败不改变 Task 业务终态 | 交付故障误判成业务失败 |
| I8 | 用户 key 只在密钥库与沙箱进程环境，不进表、事件、日志、界面、执行环境 | 凭据外泄 |
| I9 | 每个工作区外的副作用有稳定幂等键、状态、回执与补偿信息 | 恢复或重试时重复动作 |
| I10 | 预算覆盖 Task 的全部 Attempt、验收与工具调用；超限硬停 | 放大后无限额 |
| I11 | 结论与数值按 Profile 关联来源、时点、数据版本与执行者 | 证据幻觉、口径漂移 |
| I12 | 同一 thread 同一时刻只有一个方向盘持有者；交接与 Task 建单或终态同一提交 | 双写入者、等待没有 Task |
| I13 | 云端不能提高执行环境的沙箱模式、根目录与网络；只能在本机由用户抬高 | 云端攻破等于控制用户机器 |
| I14 | 每项可独立实现的义务有稳定 ID、所有者、代码位置与自动测试；未实现项显式登记 | 规范成为口号 |

这些纪律由事务、唯一约束、状态版本、令牌、持久化账与常规自动测试保证，不能只依赖提示词、执行者自律或临时脚本。

## 持久化记录

所有权威账在工作台的 PostgreSQL；沙箱与本地代理只执行与上报。什么存哪、谁是真源、留多久见 [持久化](persistence.md)。

| 记录 | 最低内容 |
| --- | --- |
| Session | 用户、环境、项目根、thread、方向盘、创建与最近活动 |
| Task / Event | 身份、契约、状态事件、因果与关联 ID、主体、时间、schema 版本 |
| Attempt | thread、turn 清单、环境、Codex 与代理版本、Profile 与专家包版本、输入输出引用、失败码、消耗 |
| 幂等账 | 作用域、键、请求摘要、Task、首次与重复响应 |
| 预算账 | Task 总额、预留、已用、释放、追加批准与拒绝原因；步骤数、耗时、turn 数由工作台控制；token 与费用标"厂商回报" |
| 副作用账 | 幂等键、目标、意图、执行状态、回执、补偿状态；工作区内改动引用 Codex 的 patch 记录 |
| 证据账 | 主张、来源、时点、数据版本、转换、生成者、Attempt 与验收者；执行内容指纹与口径表版本 |
| Interaction | 等待问题或动作、受众、待决对象摘要、令牌、状态版本、消费结果 |
| 工具级审批 | 摘要、结论、决定来源（策略或用户）、时间 |
| 本地上限变更 | 环境、项、旧值、新值、请求摘要、时间 |
| Environment | 用户、代理版本、白名单摘要、上限、在线状态、最近心跳 |
| Sandbox | 用户、Codex 版本、`CODEX_HOME` 位置、key 引用、状态 |
| 结果 | 明文正文、结构化结果、交回物、工作区路径 |
| Delivery | 目标用户与通道、cursor、尝试、确认或失败 |
