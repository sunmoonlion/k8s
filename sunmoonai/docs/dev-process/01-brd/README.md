# BRD：业务需求文档（Business Requirements Document）

回答「要什么、为什么要」：用户原话、来源与背景、意图、范围与边界、授权、待澄清的歧义，
以及与已有需求和决定的关系。归人所有；原话冻结后只追加澄清，不改写。

与 PRD 的区别：PRD 把它整理成可验证的合同，回答「做到什么算满足」。

## 提出需求的人要做到

| 要求 | 做不到会怎样 |
| --- | --- |
| 写清**边界**：含什么、不含什么、不含的归谁 | 执行者会自行扩大范围，或漏掉本该做的 |
| 给**可判定的验收标准**，不给倾向性结论 | 产出向提出者的结论收敛，等于白问 |

其余规范尚未编写。
