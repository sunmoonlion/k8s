# 开发流程规范

开发周期各阶段的通用规范：每个阶段写什么、按什么模板、过什么门。
它与任务的生命周期正交——任何开发任务（如 [`../dev-agent-task/`](../dev-agent-task/)）在任何层次、用到哪个阶段，就按该阶段的规范写；用哪几个阶段、各写多深，由任务的种类和需要决定。

- [`01-brd/`](01-brd/)：BRD（业务需求：要什么、为什么）
- [`02-prd/`](02-prd/)：PRD（产品需求与验收合同）
- [`03-sdd/`](03-sdd/)：SDD（软件设计说明：结构层与组成层）
- [`04-sdp/`](04-sdp/)：SDP（软件开发计划）
- [`05-uat/`](05-uat/)：UAT（用户验收测试）
