## 后来发现的错（2026-09-28 晚）

探针的报告原样留着，没有改。把探针改写成正式代码并逐行对照之后，发现报告里有三处不对，
详见 [`0008-info-statements`](../0008-info-statements.md)「做成正式功能时对探针的更正」：

| 报告里的说法 | 实际 |
| --- | --- |
| 美的集团的数「590 个相同、117 个只差正负号」 | 其中有 13 个数探针读错了（只读到后半截），4 个漏读 |
| 比亚迪「年报在报表页上不写单位，2017、2018 两年认到的单位不对」 | 2017、2018、2020、2021 四年的资产负债表认错。报表页上写了单位（元），探针取的是标题上方一句讲附注的话里的千元 |
| 美的集团 13 处勾稽不平「判断都是符号」 | 不全是。见上面的文档 |

`batch/extract_company.py` 里有这两个错，**不要再拿它抽数**；用 info 后端的 `report_extraction`。
