# 附录：PRD 模板（最严格的一种任务书）

只有命中 T2 判据的任务才需要填全；大多数任务一段话即可，见 [PRD 规则](prd-rules.md)「写多严，按任务轻重」。
模型只知道任务里写了的东西，所以要它遵守的一律写进来。需要时复制下面的模板作为 turn 里的 `user-message.md`，尖括号处按说明填写。怎么写、谁来写、怎么改，见 [PRD 规则](prd-rules.md)。

```markdown
---
deliverable: <SDD / SDP / UAT，可以几项>
agent: <planning / execution / acceptance>
executor: <具体执行者；未定写 unassigned。并行发给几家时改写在各尝试的 turn.md 里>
verifies: <只有 UAT 填：验收哪个 turn，用本地号，如 03 或 03b>
thread: <会话：本地会话号-执行环境的 thread id，如 01-01k8f3m2qz>
base: <发出时依据的提交>
sent_at: <发出时间>
---
# <任务编号>：<短名>

## 背景
<为什么要做；现在是什么状况；相关的已有决定和材料（给出链接）；若由某份设计拆出，写明是哪一份的哪一节>

## 要什么
<做完之后什么变了>

## 范围
- 包含：
- 不包含：
- 不包含的归谁：

## 验收标准
1. <可判定的条件，做完能一条条对着勾>

## 约束
<必须遵守的规则、不能动的东西>

## 交付
- 交回什么：<SDD / SDP / UAT 中的哪几项>；每项：<只交文本 / 会改文件，可改的范围是……>
- 需要人批准的动作：<列出；没有写「无」>
```
