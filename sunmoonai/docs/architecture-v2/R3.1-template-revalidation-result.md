## 4. 门禁基础设施修正

第一次复验在进入 Calico 子门禁前的所有阶段均通过，但 Calico 清单下载受
`raw.githubusercontent.com` 网络超时阻塞。排查同时发现旧子门禁把测试 namespace 固定为
`tpl-architecture-v2-r3`，无法安全复用其他 release namespace。已作系统修正：

- R3 主门禁默认从 schema 2 release manifest 读取 Backend/Admin/Web 不可变镜像，消除脚本
  内的重复镜像锁；仍允许显式环境变量覆盖用于诊断。
- Calico 子门禁从 bundle 的 `release.json` 解析 app 与 namespace，不再依赖固定名称。
- Calico v3.28.2 清单优先读取本地缓存，并在使用前强制校验固定 SHA-256；缓存缺失时才以
  明确连接/总时限下载，下载后仍须通过同一 SHA-256。

修正后先独立执行 Calico 正负矩阵通过，再从头执行完整 R3.1 门禁通过。第一次被人工中断的
运行没有被计入正式证据。
